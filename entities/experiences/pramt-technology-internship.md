# 프람트테크놀로지 개발팀 인턴 — Legacy-to-MSA quality validation

## Overview

2026-01~2026-02 개발팀 인턴으로 약 20만 LOC 전략물자 관리 시스템의 레거시→MSA 전환 프로젝트에서 단위·통합·운영 테스트와 개발 지원을 수행했다. Spring Boot·Thymeleaf 기반, portal/permission/judgement/destination의 4개 서버 모듈 환경이었다.

## Contribution

- 문서화되지 않은 레거시 로직과 산출물을 직접 분석해 검증 기준과 데이터 흐름을 복원했다.
- 버튼·조건 분기·신청 상태별 시나리오를 세분화해 전체 모듈에 약 8,000개 테스트 케이스를 설계·수행했다.
- 파일 업로드/다운로드 오류와 필수 첨부 조건으로 생긴 로컬 테스트 공백을 환경 조정으로 해소했다.
- 오류를 레거시 대비 차이, 재현 정보, 발생 모듈 관점으로 정리해 개발팀에 전달하고 MSA 모듈 간 인터페이스 정합성을 검증했다.
- 검색 필터 파라미터 방식의 모듈 간 불일치를 정리해 목록 복귀 시 검색 조건이 유지되는 요구 해결에 기여했다.

## Outcome

상세 기록은 1차 단위 테스트 기준 약 8,000케이스 검증, 2.6일 내 단위 테스트 에러 수정 해결률 100%, 2월 28일 운영 테스트의 데이터 이관·첨부파일 오류 100% 해결 기여를 제시한다.
