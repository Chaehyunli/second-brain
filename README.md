# 🧠 Second Brain

> 임채현의 개인 지식·경험·근거를 **내가 소유하는 Markdown 파일**로 축적하는 Obsidian Vault입니다.

## 시작점

- [[index]] — 검증된 프로젝트·경험·수상·자격·기술 지식의 지도
- [[SCHEMA]] — 사실 검증, 개인정보 보호, 파일·태그 작성 규칙
- [[AGENTS]] — Hermes·Codex·Claude 공통 작업 계약
- [[inbox/README|Inbox / Staging]] — 외부 자동 수집물·AI 초안의 검토 대기 영역
- [[knowledge/README|Knowledge]] — 여러 기준본을 출처와 함께 연결한 재사용 가능한 개념·판단 레이어
- [[log]] — Wiki에 반영한 변경 기록

## 이 Vault에 담는 것

- 프로젝트·실무·학습에서 얻은 검증 가능한 경험
- 이력서와 포트폴리오에 활용할 수 있는 원본 근거와 연결
- 기술 선택, 성과, 문제 해결의 맥락
- 시간이 지나도 다시 찾아 쓸 수 있는 개인 지식

## 원칙

1. **근거 우선** — 확인되지 않은 수치·역할·성과는 사실처럼 기록하지 않습니다.
2. **연결 우선** — 관련 노트는 위키링크로 연결합니다.
3. **개인정보 제외** — 연락처, 로그인 정보, 비밀값, 고유식별정보는 기록하지 않습니다.
4. **원본 보존** — 원본 자료는 변경하지 않고, Wiki에는 출처와 확인일을 남깁니다.

## 사용 방법

- 로컬 PC에서 이 폴더를 Obsidian Vault로 열어 탐색·수정합니다.
- Hermes는 VPS의 같은 Vault를 읽고, 근거 기반 노트를 추가·보완합니다.
- 변경 내용은 Git으로 동기화하고 이력을 보존합니다.

> 이 저장소는 private입니다. 외부 공개용 포트폴리오 저장소가 아닙니다.
