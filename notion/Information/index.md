# Information 리서치 아카이브

> Notion `Information` 하위에서 동기화한 최근 이슈·제품·기술 조사 보고서의 탐색 허브입니다.

## 연결 원칙

- 각 일반 조사 보고서는 이 문서에 최소 1개 연결을 둡니다.
- 특정 기존 노트와 **직접적인 맥락**이 확인될 때만 추가 연결을 1개 더 둡니다.
- 관련성이 약한 키워드 연결과 과도한 허브 연결은 만들지 않습니다.
- 설정·매니페스트·운영 파일은 독립 노드여도 됩니다.

이 문서는 보고서의 원문·출처·반응 지표를 대체하지 않으며, 각 보고서 Markdown 파일에 보존된 내용을 탐색하기 위한 구조적 연결점입니다.
