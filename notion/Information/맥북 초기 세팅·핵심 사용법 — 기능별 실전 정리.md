## 핵심 요약

이 문서는 macOS 초보 사용자가 바로 적용할 수 있도록 키보드·창 전환·트랙패드·Finder·앱 설치·화면 정리·iCloud·Terminal의 기본 조작을 기능별로 정리한 실전 안내다. 영상 원문과 공식 Apple 문서를 함께 출처로 보존한다. 원문에는 별도 커뮤니티 반응·조회수 지표가 기록되지 않았다.

## 1. 키보드·단축키

- macOS의 일반 편집 단축키 중심은 Windows의 `Ctrl`보다 **`Command(⌘)`** 키다.
- 기본 조합: `⌘ C`/`⌘ V`(복사/붙여넣기), `⌘ A`/`⌘ S`(전체 선택/저장), `⌘ W`(창·탭 닫기), `⌘ Q`(앱 완전 종료), `⌥ ⌘ Esc`(강제 종료), `⌘ ⇧ 5`(스크린샷·화면 녹화), `Space`(Quick Look).
- 파일을 이동할 때는 `⌘ C` 뒤 대상 폴더에서 `⌥ ⌘ V`를 사용한다. macOS Finder에는 일반적인 파일 `⌘ X`가 없다.
- 한/영 전환은 기본 키보드의 Caps Lock 위치 키를 짧게 누르는 방식이며, 입력 소스는 **시스템 설정 → 키보드 → 텍스트 입력 → 입력 소스 편집**에서 관리한다. `⌘ Space`를 입력 전환으로 바꾸면 기본 Spotlight와 충돌할 수 있다.

## 2. Spotlight·Mission Control·받아쓰기

- **Spotlight:** `⌘ Space` 또는 `F4`로 열어 앱·연락처를 빠르게 검색·실행한다.
- **Mission Control:** `F3`로 열린 창을 한눈에 보고 원하는 창으로 전환한다.
- **받아쓰기:** `F5`로 실행/종료한다. 고유명사·유행어·숫자는 인식 결과를 확인한다.

## 3. 트랙패드와 보조 클릭

1. **시스템 설정 → 트랙패드 → 포인트 및 클릭**에서 **보조 클릭**을 `두 손가락으로 클릭하기`로 설정한다.
2. Windows식 동작이 익숙하면 `하단 오른쪽 모서리에서 클릭하기`를 선택할 수 있다.
3. 설정 여부와 무관하게 `Control`을 누른 채 클릭하면 보조 클릭을 할 수 있다.
4. `탭하여 클릭하기`, 포인터 이동 속도, 클릭 감도, 자연스러운 스크롤을 손에 맞춘다.

알아둘 제스처는 두 손가락 확대/축소, 두 손가락 두 번 탭의 스마트 확대/축소, 설정한 세 손가락 제스처의 Mission Control, 엄지+세 손가락 펴기의 데스크탑 보기다.

## 4. Finder: 파일 관리와 초기 설정

- 새 폴더는 Finder 또는 데스크탑 빈 곳에서 보조 클릭 → **새로운 폴더**로 만든다.
- 이름 변경은 선택 후 `Return`, 새 Finder 탭은 `⌘`를 누른 채 더블 클릭으로 연다.
- 파일에 색상 태그를 붙이고 Finder 사이드바 태그를 클릭하면 폴더 위치와 관계없이 모아 볼 수 있다.
- 파일·폴더를 선택하고 `Space`를 누르면 Quick Look으로 앱을 열지 않고 확인할 수 있다.

권장 초기 설정:

1. Finder 빈 곳 보조 클릭 → **보기 옵션 보기** → 정렬을 `이름`으로 설정하고 필요하면 `항상 아이콘 보기`와 **기본값으로 사용**을 적용한다.
2. Finder **설정 → 새로운 Finder 윈도우에서 보기**를 `홈 폴더` 또는 `데스크탑`으로 정한다.
3. Finder **보기 → 경로 막대 보기**, **상태 막대 보기**를 켠다.
4. 자주 쓰는 폴더를 사이드바 즐겨찾기로 드래그한다. 사이드바에서 제거해도 원본 폴더는 삭제되지 않는다.

## 5. 앱 설치와 기본 앱 지정

DMG 앱은 공식 웹사이트에서 내려받아 열고, 표시된 앱 아이콘을 **Applications(응용 프로그램)** 폴더로 드래그해 설치한다. 처음 실행할 때는 개발사·서명을 확인한다.

- **Rectangle:** 창을 단축키 기반으로 세밀하게 배치하는 무료 창 정리 앱.
- **IINA:** 특수 코덱·외부 자막이 있는 동영상 재생에 쓸 수 있는 무료 플레이어.

기본 열기 앱은 대상 파일을 보조 클릭 → **정보 가져오기** → **다음으로 열기** 선택 → **모두 변경**으로 지정한다.

## 6. 화면·Dock·메뉴 막대

- **시스템 설정 → 디스플레이**에서 해상도/공간 옵션을 조절한다.
- **시스템 설정 → 데스크탑 및 Dock**에서 Dock 자동 숨김을 켜 세로 공간을 확보할 수 있다.
- Dock 아이콘을 위쪽으로 드래그하거나 보조 클릭 → **옵션 → Dock에서 제거**하면 앱을 삭제하지 않고 Dock만 정리한다.
- 메뉴 막대 아이콘은 `⌘`를 누른 채 아래로 드래그해 제거할 수 있으며, 세부 설정은 **시스템 설정 → 제어 센터**에서 한다.

## 7. 데스크탑·Hot Corner·캡처

- 데스크탑에서 보조 클릭 → **스택 사용**으로 파일을 유형별로 묶는다.
- **시스템 설정 → 데스크탑 및 Dock → 핫 코너**에서 원하는 모서리에 `데스크탑`을 지정한다. 실수 방지를 위해 지정할 때 `Control`을 함께 눌러야 발동하도록 설정할 수 있다.
- **손쉬운 사용 → 확대/축소**에서 보조 키+스크롤 확대를 켜고, 보조 키를 `Control`로 설정하면 `Control`+스크롤로 화면을 확대한다.
- `⌘ ⇧ 5`로 전체 화면·창·선택 영역을 캡처하거나 녹화하며, Preview의 마크업은 원본에 저장될 수 있으므로 필요하면 먼저 복사본을 만든다.

## 8. iCloud·외장 저장장치

**시스템 설정 → Apple 계정 → iCloud → iCloud Drive**에서 `데스크탑 및 문서 폴더` 동기화를 확인한다. 여러 Apple 기기에서 동기화할 필요가 없거나 iCloud 저장공간 압박을 줄이고 싶다면 끄는 선택이 가능하다. 외장 SSD/HDD는 구매 전 파일 시스템과 Mac/Windows 호환성을 확인하고, 포맷 전에는 반드시 백업한다.

## 9. 개발자를 위한 Terminal 기본

Terminal은 `⌘ Space`로 검색하거나 Finder **응용 프로그램 → 유틸리티 → Terminal**에서 연다.

```bash
pwd                 # 현재 위치 확인
ls                  # 현재 폴더의 파일 목록
cd ~                # 홈 폴더로 이동
cd ~/Projects/my-app  # 프로젝트 폴더로 이동(예시)
mkdir sandbox       # 새 폴더 생성
```

명령은 현재 경로를 기준으로 동작하므로, 특히 삭제 명령은 경로를 두 번 확인한다.
