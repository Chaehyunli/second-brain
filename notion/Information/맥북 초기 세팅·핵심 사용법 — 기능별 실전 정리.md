## 1. **중요 — 키보드·단축키**
### Command는 Windows의 Ctrl에 가깝다
macOS에서는 일반적인 편집 단축키의 중심이 `Control`이 아니라 **`Command(⌘)`** 키다. Windows의 Ctrl 조합을 사용하던 흐름을 Command 조합으로 바꾸면 된다.

### 한/영·Caps Lock·입력 소스
- 기본 키보드에서 **Caps Lock 위치의 한/영 키**를 짧게 누르면 한글/영어가 전환된다.
- 영어 상태에서 길게 누르면 Caps Lock이 켜지고, 다시 길게 눌러 끈다.
- 여러 언어를 쓸 때: **시스템 설정 → 키보드 → 텍스트 입력 → 입력 소스 편집 → ****`+`**에서 언어를 추가한다.
- 입력 전환 단축키를 바꾸려면: **시스템 설정 → 키보드 → 키보드 단축키 → 입력 소스**. `이전 입력 소스 선택`을 원하는 조합으로 지정한다. `⌘ Space`는 기본 Spotlight와 충돌하므로 둘 중 하나만 채택한다.
## 2. **중요 — Spotlight·Mission Control·음성 받아쓰기**
### Spotlight: 앱·연락처를 가장 빨리 여는 검색창
- **실행:** `⌘ Space` 또는 키보드의 `F4`.
- 앱 이름 일부만 입력해 실행한다. 예: 카카오톡은 `카`만 입력해도 후보에 나타난다.
- iPhone을 함께 쓰면 연락처도 빠르게 찾을 수 있다.
- 메뉴 막대의 Spotlight 아이콘은 단축키로 대체 가능하므로, 화면을 단순하게 쓰고 싶다면 제거해도 된다.
### Mission Control: 열려 있는 창을 한눈에 보고 전환
- **실행:** `F3`.
- 현재 열려 있는 창을 모두 펼쳐 보여 주므로, 큰 창을 최소화하지 않아도 다른 창으로 즉시 이동할 수 있다.
- `F3` → 원하는 창 클릭, 또는 원하는 창에 포인터를 둔 뒤 `F3`을 다시 눌러 전환한다.
### 받아쓰기
- **실행/종료:** `F5`.
- 최초에는 받아쓰기 활성화를 확인한다. 긴 문장을 빠르게 입력할 때 유용하지만 고유명사·유행어·숫자는 확인한다.
## 3. **중요 — 트랙패드 제스처·오른쪽 클릭**
[Apple 공식 트랙패드 설정 설명](https://support.apple.com/ko-kr/guide/mac-help/mchlp1226/mac)
### 보조 클릭(오른쪽 클릭)
**목적:** 파일 메뉴, 새 폴더, 정보 가져오기 등 맥의 컨텍스트 메뉴를 연다.
1. **시스템 설정 → 트랙패드 → 포인트 및 클릭**으로 이동한다.
2. **보조 클릭**을 `두 손가락으로 클릭하기`로 설정한다.
3. Windows식이 익숙하면 `하단 오른쪽 모서리에서 클릭하기`도 선택 가능하다.
4. 설정이 꺼져 있거나 급할 때는 **`Control`****을 누른 채 트랙패드를 클릭**해도 보조 클릭이 된다.
### 클릭·스크롤 권장 설정
- **탭하여 클릭하기:** 물리적으로 누르지 않고 한 손가락으로 톡 건드려 클릭한다. 손가락 피로를 줄이는 설정이다.
- **이동 속도 / 클릭 감도:** 포인터 이동과 누르는 힘을 본인 손에 맞춘다.
- **자연스러운 스크롤:** 손가락을 움직인 방향으로 콘텐츠가 이동한다. 스마트폰과 같은 감각이 편하면 켜고, 마우스 휠 감각이 편하면 끈다.
- 외장 마우스를 연결하면 **시스템 설정 → 마우스**에서 별도 스크롤 설정을 한다.
### 알아둘 제스처
- 두 손가락 오므리기/펴기: 확대·축소
- 두 손가락 두 번 탭: 스마트 확대/축소
- 세 손가락 또는 설정한 제스처: Mission Control
- 엄지+세 손가락 펴기: 데스크탑 보기(기기·설정에 따라 다름)
## 4. **중요 — Finder: 파일 관리자·정리·설치의 중심**
### 파일·폴더 관리
- 새 폴더: 바탕화면/Finder 빈 곳 **보조 클릭 → 새로운 폴더**.
- 이름 변경: 파일·폴더를 선택한 뒤 `Return`을 누르거나, 이름을 한 번 더 클릭한다.
- Finder 탭: 폴더를 **`⌘`****를 누른 채 더블 클릭**하면 새 탭으로 연다. 탭 하나만 닫을 때는 `⌘ W`.
### 태그로 파일을 가로질러 분류
**목적:** 폴더 위치가 달라도 ‘중요’, ‘제출’, ‘프로젝트’처럼 같은 성격의 파일을 한 번에 모은다.
1. 파일을 보조 클릭한다.
2. 색상 태그(예: 빨간색)를 추가한다.
3. Finder 왼쪽 사이드바의 해당 태그를 클릭하면 같은 태그의 파일을 모두 본다.
### Quick Look(미리보기)
파일·동영상·문서·폴더를 선택하고 **`Space`**를 누른다. 앱을 열지 않고 내용을 빠르게 확인하고, 폴더/외장 저장장치의 용량도 볼 수 있다.
### Finder 초기 세팅
**목적:** 아이콘이 옆으로 흩어지거나 파일이 창 밖에 숨는 문제를 막고, 자주 쓰는 위치와 경로를 명확하게 한다.
1. Finder에서 빈 곳을 보조 클릭 → **보기 옵션 보기**.
2. **정렬**을 `없음`이 아닌 `이름`으로 변경한다.
3. 필요하면 `항상 아이콘 보기`를 켠다.
4. **기본값으로 사용**을 눌러 새 Finder 창에도 적용한다.
5. Finder 메뉴 → **설정 → 새로운 Finder 윈도우에서 보기**를 `홈 폴더` 또는 `데스크탑`으로 바꾼다. 최근 항목 대신 작업 시작 위치를 고정한다.
6. Finder 메뉴 → **보기 → 경로 막대 보기**, **상태 막대 보기**를 켠다.
	- 경로 막대: 현재 폴더의 위치를 보며, 경로 우클릭으로 이름을 복사할 수 있다.
	- 상태 막대: 선택 파일 수와 남은 저장공간을 확인한다.
7. 자주 쓰는 폴더는 사이드바로 드래그해 즐겨찾기에 넣고, 필요 없는 항목은 사이드바 밖으로 드래그해 제거한다. **원본 폴더가 삭제되는 것은 아니다.**
## 5. 앱 설치·기본 앱 지정
### DMG 앱 설치 방식
**목적:** 웹에서 내려받은 Mac 앱을 응용 프로그램 폴더에 설치한다.
1. 공식 웹사이트에서 앱을 내려받는다.
2. 다운로드된 `.dmg` 파일을 연다.
3. 열린 창에서 앱 아이콘을 **Applications(응용 프로그램)** 폴더 아이콘으로 드래그한다.
4. Launchpad, Spotlight 또는 응용 프로그램 폴더에서 앱을 실행한다.
<callout icon="⚠️" color="orange_bg">
	앱은 공식 개발사·App Store 등 신뢰할 수 있는 출처에서만 설치한다. 처음 실행 시 macOS 보안 경고가 나면 개발사와 서명을 확인한 뒤 진행한다.
</callout>
### 영상 추천 앱
- **Rectangle:** 창을 좌/우/상단 등 원하는 영역으로 배치하는 무료 창 정리 앱. Windows의 스냅보다 세밀한 단축키 기반 배치를 제공한다.
- **IINA:** 특수 코덱·외부 자막 파일이 있는 동영상을 재생하기 좋은 무료 플레이어. 기본 QuickTime에서 재생이 불편한 경우의 대안이다.
### 음악·동영상 기본 앱 변경
1. 대상 확장자의 파일 하나를 보조 클릭 → **정보 가져오기**.
2. **다음으로 열기**에서 IINA 또는 QuickTime Player를 고른다.
3. **모두 변경** → 확인. 이후 같은 확장자는 선택한 앱으로 열린다.
## 6. 화면·Dock·메뉴 막대 작업공간 정리
### 디스플레이와 Dock
- **화면 정보량 조절:** 시스템 설정 → **디스플레이** → 해상도/공간 옵션. 더 넓게 쓰면 창은 작아지고, 글자가 작다면 왼쪽의 큰 텍스트 쪽을 택한다.
- **Dock 자동 숨김:** 시스템 설정 → **데스크탑 및 Dock → Dock 자동으로 가리기 및 보기**. 세로 공간을 확보한다.
- **Dock 정리:** 아이콘을 Dock 밖으로 위쪽 드래그하거나, 보조 클릭 → **옵션 → Dock에서 제거**. 앱 자체는 삭제되지 않는다.
- **Dock에 고정:** Launchpad 또는 Finder에서 앱/자주 쓰는 폴더를 Dock으로 드래그한다.
- **응용 프로그램 폴더 고정:** Finder 사이드바의 `응용 프로그램`을 Dock으로 드래그하면 Launchpad 대신 빠르게 앱 목록을 열 수 있다.
- **최근 앱 숨김:** Dock 빈 공간 보조 클릭 → Dock 설정 → `Dock에서 최근 사용한 응용 프로그램 보기`를 끈다.
### 메뉴 막대·포인터·사운드
- 메뉴 막대 아이콘은 **`⌘`****를 누른 채 아래로 드래그**해 제거할 수 있다. 복구/세부 설정은 **시스템 설정 → 제어 센터**에서 한다.
- 포인터가 작거나 잘 안 보이면 시스템 설정 검색에서 `포인터 크기`를 찾아 크기·색상을 조절한다. `마우스 포인터를 흔들어 찾기`를 켜면 커서를 흔들 때 커진다.
- 시스템 설정 → **사운드 → 음량이 변경될 때 피드백 재생**을 켜면 볼륨 변경 시 효과음으로 현재 크기를 가늠할 수 있다.
## 7. 데스크탑 정리·모든 창 숨기기·Hot Co\`rner
### 스택으로 바탕화면 정돈
바탕화면 보조 클릭 → **스택 사용**. 이미지·동영상·문서 등 유형별로 자동 묶는다. 단, 파일이 너무 많으면 스택 안도 복잡해지므로 주기적으로 정리한다.
### Hot Corner로 데스크탑 즉시 보기
**목적:** 여러 창을 하나씩 최소화하지 않고 바탕화면 파일에 즉시 접근한다.
1. 시스템 설정 → **데스크탑 및 Dock** → 맨 아래 **핫 코너**.
2. 원하는 모서리(영상 예시: 오른쪽 아래)를 `데스크탑`으로 지정한다.
3. 실수로 발동하는 것을 막으려면 선택 시 **`Control`****을 누른 채** `데스크탑`을 고른다.
4. 이후 `Control`을 누른 채 지정한 모서리로 포인터를 보내야만 작동한다.
## 8. 화면 확대·스크린샷·마크업
### 보조 키+스크롤 확대
- 시스템 설정 → **손쉬운 사용 → 확대/축소**.
- **보조 키와 함께 스크롤 제스처를 사용하여 확대/축소**를 켠다.
- 보조 키를 `Control`로 두면 `Control` + 스크롤로 화면 전체를 부드럽게 확대한다.
### 캡처와 화면 녹화
`⌘ ⇧ 5`를 눌러 패널에서 전체 화면·창·선택 영역 캡처 또는 녹화를 고른다. 촬영 뒤 오른쪽 아래에 뜨는 미리보기는 문서로 바로 드래그할 수 있다. 다만 **미리보기만 드래그해 다른 앱에 넣으면 별도 파일 저장은 되지 않을 수 있다.**
### Preview(미리보기) 마크업
이미지/PDF를 Preview로 열고 **마크업** 버튼을 누른다.
- 펜, 선, 화살표, 사각형, 색상, 선 두께로 빠르게 주석을 단다.
- 저장은 `⌘ S`. 원본에 적용되므로 수정 전 파일은 복사해 두는 편이 안전하다.
## 9. iCloud·외장 저장장치
### iCloud의 ‘데스크탑 및 문서 폴더’ 동기화 확인
**목적:** 데스크탑·문서의 대용량 파일이 iCloud 용량을 빠르게 소진하지 않도록 제어한다.
1. 시스템 설정 → 맨 위 **Apple 계정** → **iCloud**.
2. **iCloud Drive** → `데스크탑 및 문서 폴더`를 확인한다.
3. 영상의 권장값은 이 항목을 **끔**이다. 그러면 파일은 Mac 로컬에 저장되어 iCloud 공간 압박을 줄인다.
<callout icon="ℹ️" color="gray_bg">
	여러 Apple 기기에서 데스크탑·문서 동기화가 꼭 필요하거나 iCloud 저장공간이 충분하다면 켜도 된다. 핵심은 필요성과 저장공간을 확인한 뒤 선택하는 것이다.
</callout>
### 외장 SSD/HDD
영상은 일부 외장 저장장치가 바로 쓰기 어려울 수 있어 별도 설정이 필요하다고 안내한다. 구매 전 파일 시스템과 Mac/Windows 호환 필요 여부를 확인하고, 기존 데이터가 있으면 **포맷 전에 백업**한다.
## 10. **중요 — 개발자를 위한 Terminal 실행·기본 사용**
<callout icon="🧑‍💻" color="purple_bg">
	이 항목은 사용자의 필수 요청에 따른 **개발자 보충**이다. 원문 스크립트에는 Terminal 실습이 직접 포함되어 있지 않다.
</callout>
### Terminal 실행 3가지
1. **Spotlight:** `⌘ Space` → `Terminal` 입력 → `Return`.
2. **Finder:** Finder → 응용 프로그램 → 유틸리티 → **Terminal**.
3. **Launchpad/응용 프로그램 Dock 폴더:** Terminal을 찾아 실행.
### 처음 쓸 때 알아둘 최소 명령
```bash
# 현재 위치 확인
pwd

# 현재 폴더의 파일 목록 확인
ls

# 홈 폴더로 이동
cd ~

# 프로젝트 폴더로 이동(예시)
cd ~/Projects/my-app

# 새 폴더 생성
mkdir sandbox
```
- 명령은 **현재 경로**를 기준으로 동작한다. 위험한 삭제 명령은 경로를 두 번 확인한 뒤 실행한다.
- 개발 도구 설치·Git·Node·Python 작업은 Terminal에서 수행하지만, 처음에는 `pwd`, `ls`, `cd`로 위치 이동부터 익히면 충분하다.
