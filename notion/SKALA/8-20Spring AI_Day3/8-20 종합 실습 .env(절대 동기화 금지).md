# 종합 실습 .env(절대 동기화 금지)

## 원문

[Notion 원문](https://app.notion.com/p/3c21d84bf68e804cb269e0cb5d89ab40)

```plain text
# .env 는 절대 제출 ZIP에 넣지 않는다. OPENAI 키는 OpenAI Platform에서 발급한 뒤 아래에 입력한다.
# OPENAI_API_KEY=

# ── 주가 조회: Finnhub (무료 가입) ────────────────────────────
# 발급: https://finnhub.io/register 가입 → 대시보드에서 API Key 복사 (즉시 발급, 카드 불필요)
FINNHUB_API_KEY=da3bla1r01qupvfcerugda3bla1r01qupvfcerv0

# ── 이메일 발송: Gmail SMTP ───────────────────────────────────
# 발급: 구글 계정 →보안 → 2단계 인증 활성화 → "앱 비밀번호" 생성(메일 앱용 16자리)
# MAIL_PASSWORD 에는 구글 로그인 비밀번호가 아니라 이 앱 비밀번호를 넣는다.
MAIL_USERNAME=chaehyun010104@gmail.com
MAIL_PASSWORD=xdks uudc vvnk warb
COMPLIANCE_MAIL_TO=chaehyun010104@gmail.com

# ── 관리자 승인 API 게이트 ────────────────────────────────────
ADMIN_KEY=changeme

# ── pgvector / Postgres (docker-compose.yml 기본값과 반드시 일치) ─
DB_URL=jdbc:postgresql://localhost:5434/helpdesk
DB_USERNAME=helpdesk
DB_PASSWORD=helpdesk

```
