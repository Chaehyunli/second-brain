# SKALA 개발환경 설치 스크립트 — 원문·주석·동작 해설

## 원문 스크립트

[`skala-config-setup.sh` 전체 원문 열기·다운로드](https://h.uguu.se/aLaiyQwt.sh)

이 문서는 제공된 설치 스크립트를 학습용으로 해설한다. 실제 실행 전에는 외부 스크립트의 출처·변경 내용을 검토하고 개인 계정 및 업무 장비 정책에 맞는지 확인한다.

## 스크립트의 목적

맥북 교육생의 개발 환경을 표준화한다. Apple Silicon/Homebrew 경로를 판별하고 Rosetta 2, Xcode CLT, Homebrew, Git, zsh, Java 21, Python 3.11, Node.js, PostgreSQL, VS Code, Docker, iTerm2, AWS CLI, kubectl을 설치한다. `.zprofile`과 `.zshrc`에는 PATH·별칭을 한 번만 추가하며, 실패 항목은 마지막에 모아 보고한다.

## 구현상 핵심

- `set -uo pipefail`을 사용하고 `set -e`는 사용하지 않아 개별 설치 실패 뒤에도 가능한 단계를 계속 수행한다.
- `try` 함수는 실패 항목을 기록하면서도 다음 단계를 진행한다. Homebrew처럼 기반 의존성은 별도로 중단 처리한다.
- `sudo -v`와 keepalive 루프로 설치 중 인증을 유지하며, 종료 시 `trap`으로 백그라운드 프로세스를 정리한다.
- `append_block_once`는 고유 마커를 검사해 PATH와 alias 설정이 중복되지 않게 한다.
- `brew_install_formula`, `brew_install_cask`, 전역 npm 설치 헬퍼는 이미 설치된 항목을 건너뛴다.

## 주의 사항

- Homebrew 설치와 Oh My Zsh 설치은 원격 코드를 실행하므로 공식 출처와 조직 정책을 먼저 확인한다.
- macOS의 `sed -i ''` 문법은 Linux GNU sed와 다르다.
- Docker Desktop은 설치 후 GUI 앱을 한 번 실행해 daemon과 권한 절차를 완료해야 한다.
- 설치 후에는 도구 버전, PostgreSQL 서비스, Docker 동작, VS Code 확장, Git 사용자 정보와 `.gitignore`를 확인한다.
- `.env`, PAT, API 키와 비밀번호는 Git에 커밋하지 않는다.

## 설치 후 검증

```bash
source ~/.zprofile
source ~/.zshrc
brew --version
git --version
java -version
python3.11 --version
node -v
docker version
psql --version
```

## 핵심 정리

이 스크립트의 핵심은 단순 설치가 아니라 재실행 가능한 환경 표준화다. 실패를 기록하면서 진행하고 이미 설치된 패키지·설정은 건너뛰며, 최종 버전·서비스·종료 코드로 상태를 검증한다.
