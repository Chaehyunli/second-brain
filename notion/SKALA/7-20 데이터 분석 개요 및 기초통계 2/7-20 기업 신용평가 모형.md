# [7/20] 기업 신용평가 모형

> 원본 Notion 학습 페이지: https://app.notion.com/p/3a31d84bf68e80158349fcfaed79619c

## 원문 상태와 범위

원문은 여러 이미지와 아래의 짧은 메모로 구성되어 있다. 이미지 URL은 만료형 서명 URL이므로 보관하거나 자동으로 내용을 판독하지 않았다. 따라서 이 노트는 본문에 실제로 적힌 메모만 보존하며, 이미지에만 들어 있는 신용평가 모형의 세부 내용은 추정하지 않는다.

## 분포 모양과 전처리

- **정규형**은 원문에서 이상적인 형태로 표시됐다.
- **피크형**은 독립변수의 퍼짐이 좁아 불편 추정량이 좋지 않다고 메모되어 있다.
- 원문은 **Scaling**을 전처리와 연결하며, 전처리가 잘 된 데이터셋은 어떤 모델에 적용해도 어느 정도 성능이 나온다고 적었다.

## 선형성 확인 메모

- 원문의 첫 번째 그림은 선형으로 보이며 매우 좋다고 설명한다.
- 두 번째 그림은 선형이 아니어서 좋지 않은 그림으로 구분한다.
