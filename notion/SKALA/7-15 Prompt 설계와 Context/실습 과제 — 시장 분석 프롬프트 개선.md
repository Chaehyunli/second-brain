# [7/15] 실습 과제 — 시장 분석 프롬프트 개선

## 과제 목표
단문 시장 분석 요청을 **검증 가능한 경영진용 의사결정 보고서**로 개선한다.

## Baseline의 한계
- 시장 규모·경쟁사·고객·SWOT·진입 전략이 같은 기준으로 연결되지 않았다.
- 수치와 주장에 원문 출처·기준일·적용 범위가 없어 검증하기 어려웠다.
- 긴 설명과 사실·해석이 섞여 의사결정에 바로 쓰기 어려웠다.

## 프롬프트 개선 방식
- **Role / Objective / Context / Constraints / Format**으로 가상 기업, 제품 범위, 채널, 예산과 산출물 구조를 명시했다.
- 공식 통계·공시·브랜드 자료 우선, 근거 ID·기준일·적용 범위·해석 한계를 요구했다.
- Step-back으로 시장 정의와 판단 기준을 먼저 세우고, Few-shot으로 사실·해석·한계·의사결정 표기 방식을 고정했다.
- Pre-mortem으로 신뢰 부족·가격 수용성·전환율·재고 회전의 실패 가설과 대응을 검토했다.

## 결과 해석
좋은 결과는 정보를 많이 넣는 것보다 **범위, 근거, 출력 형식, 검증 기준을 제약으로 설계**했을 때 나온다.

## 보충 — [7/15] 실습 과제 - 흐름
- **1단계:** 시장 규모·경쟁사·고객·SWOT·전략의 기준이 분리되어 있지 않은 baseline을 확인한다.
- **2단계:** 출처 부재, 구조화 부족, 모호한 해석을 검증 가능성·문서 구조·판단 기준 관점에서 진단한다.
- **3단계:** 역할·목표·회사 조건·출처 제약·출력 형식에 Step-back, Few-shot, Pre-mortem을 결합해 프롬프트를 재설계한다.
- **4단계:** 시장 정의, 근거 ID, 경쟁 비교, 고객, SWOT, 실행 전략과 실패 대응이 연결된 보고서로 결과를 평가한다.
