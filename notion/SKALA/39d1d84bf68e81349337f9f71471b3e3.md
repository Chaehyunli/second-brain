# [7/14] Git & AI코딩 & 환경구성 — 강의 정리

## 학습 목표
맥북 개발 환경을 준비하고 웹·서버·Git의 기본 개념을 이해한 뒤, VS Code와 GitHub로 첫 결과물을 배포하고 OpenAI Codex CLI로 AI 코딩을 경험하는 흐름을 다룬다.

## 핵심 내용

- **IT 용어:** Wireframe, Mock-up, Prototype, Persona, UI/UX, Storyboard, Navigation, Design System/IA의 차이를 이해한다. MVP·Release·Launch·Go-Live·Deployment·Rollout·Hotfix·Rollback의 운영 의미를 구분한다.
- **인프라와 애자일:** 물리 서버·VM·Bare Metal, 데이터센터·온프레미스, 백업·복구, 배치·모니터링·로깅의 기본 개념을 다룬다. Agile, Scrum, Kanban, Sprint, Backlog, DoD와 각 역할을 정리한다.
- **웹 구조:** 프론트엔드는 HTML·CSS·JavaScript와 API 표시를, 백엔드는 검증·계산·저장·인증·로깅을 담당한다. MPA는 서버 렌더링, SPA는 클라이언트 렌더링과 JSON API 중심이다.
- **개발 환경:** SKALA 제공 스크립트로 Xcode, Homebrew, Git, JDK 21, Python 3.11, Node.js, PostgreSQL, VS Code, Docker, AWS CLI, kubectl 등을 설치한다. 설치 뒤 각 도구의 버전을 확인하고 Docker를 최초 실행한다.
- **Git/VS Code:** `git status → add → commit → push` 흐름, `.gitignore`, 브랜치·병합·충돌·PR을 다룬다. `.env`, PAT, API 키, 비밀번호는 절대 커밋하지 않으며 노출되면 즉시 폐기·재발급한다.
- **AI 코딩:** Codex CLI는 생성 후 이해·리뷰·테스트·실행 검증의 순서로 사용한다. 첫 결과물은 실제로 실행하고, 코드 리뷰와 테스트를 함께 요청한다.
