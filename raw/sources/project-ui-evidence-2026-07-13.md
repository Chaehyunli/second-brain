# 프로젝트 UI·사용자 흐름 근거 — 2026-07-13

## Masil

사용자 제공 `v5.pdf`의 실제 모바일 앱 패널을 화면별로 분리한 Notion UI 기록을 확인했다. 홈의 AI 플래너 진입, 자연어 대화 기반 일정·예약 후보 제안, 예약 상태 조회, Day별 일정 편집, 여행 당일 진행·길 안내 흐름을 담는다. 기기에 직접 접근하지 못한 환경이므로 웹으로 임의 재현하지 않았다는 제한이 명시돼 있다.

## PETNER

프론트엔드 로컬 실행과 API fixture로 회원·유기견·보호소·게시글·채팅 데이터를 렌더링한 화면 기록을 확인했다. 유기견 조회·등록, 보호소 상담, 분양 신청, 신청 승인/거절과 `입양 가능 → 대기 → 승인 → 입양 절차 중 → 입양 완료` 상태 흐름을 포함한다. 실제 backend·DB·배포에는 연결하지 않은 검증 범위다.

## 동아리모아

로컬 React 프론트엔드를 가상 동아리·회원·지원자 데이터로 렌더링한 UI 기록을 확인했다. 계정 진입, 동아리 탐색, 지원서 작성, 운영자의 지원자 처리, 역할 관리, 1:1 채팅 화면을 포함한다. 저장·승인 반영·권한 변경 API 및 실제 WebSocket 메시지 전달은 검증 범위 밖이다.

## 노소공

사용자 제공 포트폴리오 PDF에 포함된 실제 모바일 앱 원본 화면을 사용한 기록을 확인했다. 감정·편애도·재화 게이지, 케어 행동, 놀이 상점과 `POST /api/v1/cares/action` 응답을 화면 상태에 반영하는 흐름을 담는다.
