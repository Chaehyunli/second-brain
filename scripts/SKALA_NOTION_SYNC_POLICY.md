# SKALA Notion → Obsidian daily sync policy

- Source root: Notion `SKALA` page `39d1d84b-f68e-80f3-89b7-e70a6c911bf9`.
- Scope: recursively discover and sync all descendant pages. Do not follow pages outside this ancestor tree.
- Destination: `notion/SKALA/` in this Vault. Sync **only leaf pages containing learning material**. A leaf has no direct descendant `<page url=...>` within the SKALA tree. Do not create a SKALA index or any parent/hub note. One eligible page maps to one Markdown note with `notion_page_id`, source URL, title, sync timestamp, and `content_sha256` in frontmatter. The filename uses the Notion title after replacing Windows-unsafe characters (`\\ / : * ? " < > |`) with `-`; use `notion_page_id` rather than filename as the stable identity.
- Skip non-learning administrative/orientation material, including the `[7/14] OT` page and attendance, mobile attendance, security pledge, schedule, campus, meal, operation, allowance, certificate, contact, and attendance-recognition information. SKALA notes contain learning material only.
- Preserve the eligible page's meaningful Markdown content and original Notion URL. Do not archive temporary signed image URLs as durable evidence; retain stable text and page references.
- Extract only the Notion `<content>` region, remove temporary signed-image URLs, normalize whitespace, then calculate `content_sha256` from that source text. Compare this source hash before writing: update only newly discovered or changed eligible leaf pages. A missing hash is a one-time baseline migration. Do not delete an eligible leaf simply because a remote page is temporarily unavailable; remove an existing local note only when the current tree proves it is non-leaf or non-learning.
- Safety: stop before writing or committing if `git status --porcelain` reports unrelated local changes. Do not use reset or force push.
- Commit each changed learning leaf separately and use its exact Notion title: `노션: SKALA - <페이지 제목> 업데이트`. When removing pages that are now proven non-leaf or non-learning, use `노션: SKALA - 학습 외 페이지 정리`.
- Push each successful commit to `origin/main`. If no page changed, make no commit and return no user-facing report.
