- Scope: recursively discover and sync all descendant pages. Do not follow pages outside this ancestor tree.
- Destination: `notion/SKALA/` in this Vault. Sync **only leaf pages containing learning material**. Determine hierarchy from an actual child-page relationship, not from arbitrary `<page>` references inside a page body; a linked reference alone does not make a page non-leaf. The filename uses the Notion title after replacing Windows-unsafe characters (`\\ / : * ? " < > |`) with `-`; when the page is under a dated SKALA parent such as `[7/15]`, prefix the filename with `7-15 ` even if the leaf title omits the date. Use `notion_page_id` rather than filename as the stable identity.

- For the daily hook's identity check, recursively scan every Markdown note under `notion/SKALA/` for `notion_page_id`; manually added nested notes are also frozen after their first commit.
- Extract only the Notion `<content>` region, remove temporary signed-image URLs, normalize whitespace, then calculate `content_sha256` from that source text for a new note's provenance. **An uploaded eligible leaf is frozen after its first GitHub commit:** a later change to that same `notion_page_id` must not update its body, title, filename, hash, timestamp, links, or Git history unless the user explicitly requests it.
- For a **new** eligible page ID, compare its learning purpose and key concepts against the existing SKALA notes before writing. If it is materially identical, do not add a note. If it is closely related but adds distinct learning value, append a short `## 보충 — <새 페이지 제목>` section at the end of the closest existing note, with the new Notion URL; do not alter the existing sections. Do this only once per new source URL. Otherwise create a separate note.
- Safety: stop before writing or committing if `git status --porcelain` reports unrelated local changes. Do not use reset or force push.
- Commit each newly added learning leaf separately and use its exact Notion title: `노션: SKALA - <페이지 제목> 업데이트`. For a supplement, use `노션: SKALA - <새 페이지 제목> 보충`. Never create an automatic update or deletion commit for an already uploaded page itself.
- Push each successful commit to `origin/main`. If no page changed, make no commit and return no user-facing report.
