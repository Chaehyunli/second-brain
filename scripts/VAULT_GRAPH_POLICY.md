# Vault 그래프 연결 정책

## 적용 대상

Obsidian Vault에 새로 저장·동기화·생성하는 일반 문서와 기존 문서 점검에 적용한다.

## 규칙

1. 일반 문서는 기존의 **의미 있는 노드 연결을 최소 1개** 가져야 한다. 단, `notion/Information/`의 Notion **원문 미러 파일**은 원문 충실성을 위해 본문 내 위키링크 삽입 대상에서 제외한다.
2. 동기화 전 Vault를 검색해 직접적 맥락이 있는 문서·주제 허브를 고른다. 원문 미러 파일은 `scripts/INFORMATION_NOTION_SYNC_POLICY.md`를 우선 적용한다.
3. 기본 연결 1개 외에는 직접적이고 구체적인 관계가 있을 때만 최대 1개를 추가한다.
4. 키워드만 비슷한 문서, 임의의 인기 허브, 다수의 자동 링크는 만들지 않는다.
5. 설정·매니페스트·스크립트·운영 정책 파일은 독립 노드여도 된다.
6. 카테고리/아카이브 허브는 하위 문서를 연결하는 용도로 사용하며, 원문 링크·근거를 대체하지 않는다.
7. Notion 원본 제목에 `(수정중)`이 포함된 페이지는 미완성으로 취급한다. Obsidian·GitHub에 새 문서로 동기화하거나 기존 문서를 보충하지 않고, 제목에서 해당 표기가 사라진 뒤에만 일반 동기화 대상으로 다시 판단한다.

## 점검

GitHub push 전 신규·수정 Markdown의 링크가 실제 Vault 노드를 가리키는지 확인한다. 고립 노드가 있으면 의미 있는 허브 또는 직접 관련 문서와 연결하고, 적절한 관계가 없으면 이유를 기록한다.
