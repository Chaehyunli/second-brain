## 학습 목표

## 원문 기반 학습 내용

## 이산

### 1.확률변수 (Random Variable)

**확률변수**는 어떤 실험이나 상황에서 나올 수 있는 결과를 **수치로 나타낸 변수**입니다. 확률변수는 주사위를 굴리거나 동전을 던지는 등의 실험 결과를 수치화하는 데 사용됩니다.

---

#### 예시: 주사위 굴리기

* 주사위를 한 번 굴리는 실험을 생각해 봅시다.
* 이때 나올 수 있는 숫자는 **1, 2, 3, 4, 5, 6**입니다.
* 주사위의 눈에 대응하는 확률변수 $X$는 **1, 2, 3, 4, 5, 6**의 값을 가질 수 있습니다.
이처럼 확률변수는 주사위 결과와 같은 실험의 가능한 결과를 수치로 나타냅니다.

---

### 2. 확률분포 (Probability Distribution)

**확률분포**는 각 **확률변수**가 특정 값을 가질 **확률**을 나타내는 함수입니다. 확률분포는 확률변수가 가질 수 있는 **모든 값**과 그에 대응하는 **확률**을 보여줍니다.

---

#### 예시: 주사위 확률분포

주사위에서 각 눈이 나올 확률은 모두 동일합니다. 주사위의 각 숫자가 나올 확률을 나타내는 확률분포는 다음과 같습니다:

* $P(X = 1) = \frac{1}{6}$
* $P(X = 2) = \frac{1}{6}$
* $P(X = 3) = \frac{1}{6}$
* $P(X = 4) = \frac{1}{6}$
* $P(X = 5) = \frac{1}{6}$
* $P(X = 6) = \frac{1}{6}$

이 경우, 확률분포는 주사위의 각 숫자가 나올 확률을 보여줍니다.
---

## 연속

### 1. 연속 확률변수 (Continuous Random Variable) 📏

**연속 확률변수**는 특정 값이 아닌, **범위 내의 값**을 가질 수 있는 확률변수입니다. 이산확률변수와 달리, 연속 확률변수는 **무한히 많은 값**을 가질 수 있습니다.

* 따라서 연속 확률변수에서 **특정 값**이 나올 확률은 항상 **0**입니다.
* 대신, 특정 **구간의 확률**을 계산합니다.

---

#### 예시: 사람의 키

사람의 키를 확률변수 $X$라고 합시다.

* 사람의 키는 150cm, 160cm, 170cm와 같이 이산적인 값이 아니라 **150cm부터 200cm 사이의 모든 값**을 가질 수 있는 연속적인 변수입니다.
* $X$는 150cm에서 200cm 사이의 어떤 값을 가질 수 있습니다.
* 예를 들어, 사람의 키가 **정확히 170cm일 확률은 0**입니다. 하지만 **170cm에서 175cm 사이**에 속할 확률은 구할 수 있습니다.

---

### 2. 연속확률분포 (Continuous Probability Distribution)

**연속확률분포**는 연속 확률변수의 확률분포를 **확률밀도함수(Probability Density Function, PDF)**로 표현합니다. 확률밀도함수는 특정 구간에서의 확률을 구하는 데 사용되며, 확률은 함수의 그래프 아래 면적으로 계산됩니다. 이 면적은 전체 1이 되어야 합니다.

---

#### 예시: 사람의 키 확률밀도함수

사람의 키가 150cm에서 200cm 사이에 있다고 가정하고, 이 구간에서의 확률밀도함수를 그려보면, 아래와 같은 곡선이 나올 수 있습니다. 이 곡선 아래 면적의 합은 1입니다. 특정 구간, 예를 들어 160cm에서 170cm 사이의 확률은 곡선 아래 그 구간에 해당하는 면적으로 계산됩니다.

* $P(160 \le X \le 170)$는 160cm에서 170cm 사이의 키가 나올 확률로, 이 구간에서의 곡선 아래 면적을 구합니다.
* 확률밀도함수 아래 면적의 합은 항상 1입니다.

---

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# 주사위 값(확률변수)
dice_values = np.arange(1, 7)
print( 'dice_values:', dice_values)
# 주사위 각 면이 나올 확률 (1/6): 확률분포
probabilities = np.repeat(1/6, 6)
print('probabilities',probabilities)

# 막대그래프 시각화(이산확률분포의 시각화)
plt.bar(dice_values, probabilities)
plt.xlabel("Dice Value")
plt.ylabel("Probability")
plt.title("Discrete Probability Distribution of a Fair Dice")
plt.show()

# 확률분포 데이터 출력
df = pd.DataFrame({
    "Dice_Value": dice_values,
    "Probability": probabilities
})
df

# 확률변수: dice_values (주사위 눈 1 ~ 6)
# 확률분포: df 데이터프레임 전체 또는 dice_values와 probabilities 배열의 대응 관계.
```

### 원문 코드 실습 2

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy.stats import norm

# 평균과 표준편차 설정
mu = 170   # 평균
sigma = 10  # 표준편차

# 100명의 사람 키를 정규분포에서 샘플링
np.random.seed(42)  # 재현 가능한 결과를 위해 시드 설정

## 확률변수:sample_heights
#평균이 170이고 표준편차가 10인 모집단에서 샘플링된 100명의 키 값.
#키는 연속적인 값(예: 170cm부터 175cm 사이의 모든 값)을 가질 수 있는 연속 확률변수.
sample_heights = np.random.normal(loc=mu, scale=sigma, size=100)
print('sample_heights', sample_heights)
#확률분포 (Probability Distribution)
#정의: 연속 확률변수의 확률분포는 **확률밀도함수(PDF)**로 표현되며, 확률은 함수의 그래프 아래 면적으로 계산됩니다.
#코드 상의 위치: 코드에서 생성하고 시각화하는 **정규분포(Normal Distribution)**가 확률분포에 해당

# 히스토그램 (밀도형)
plt.hist(sample_heights, bins=10, density=True, color='green')
plt.xlabel("Height (cm)")
plt.ylabel("Probability Density")
plt.title("Histogram of 100 Sample Heights with Normal Distribution")

# 정규분포 곡선 추가
x = np.linspace(min(sample_heights), max(sample_heights), 100)
y = norm.pdf(x, mu, sigma)
plt.plot(x, y)

plt.show()
```

##  확률 밀도(Probability Density) 계산 과정

히스토그램(histogram)을 그릴 때 `density=True` 옵션을 사용하면
막대 높이가 “빈도수”가 아니라 “확률 밀도(Probability Density)”가 된다.

확률 밀도 계산과정.

---

### 1. 구간(bin)의 너비(계급) 계산

히스토그램은 데이터를 여러 개의 **구간(bin)** 으로 나누어 표현.
구간의 개수는 `bins` 옵션으로 결정.

예)
- 데이터 범위: 0 ~ 100
- `bins=10`
→ 데이터를 10개 구간으로 나누고,
→ 각 구간의 너비(bin width:계급)는:
$$
\frac{100 - 0}{10} = 10
$$

- 데이터 범위: 150 ~ 190
- `bins=10`
→ 데이터를 10개 구간으로 나누고,
→ 각 구간의 너비(bin width)는:
$$
\frac{190 - 150}{10} = 4
$$

---

### 2. 각 구간의 빈도수 계산

각 구간에 몇 개의 데이터가 들어가는지 세는 과정입니다.

예)
- 첫 번째 구간에 8개 데이터가 들어갔다면 → 빈도수 8

---

### 3. 확률 밀도 계산

확률 밀도는 다음 공식으로 계산됩니다:

$$
\text{확률 밀도} =
\frac{\text{구간의 빈도수}}{\text{전체 데이터 수} \times \text{구간 너비}}
$$

즉,
- 빈도수만으로는 확률의 의미가 부족하므로
- 구간 너비를 고려하여 **밀도(density)** 로 바꾼 값입니다.

---

### 4. 전체 면적이 1이 되도록 조정

확률 밀도를 사용한 히스토그램은
각 막대의 면적(높이 × 구간 너비)을 모두 더하면 **항상 1**이 됩니다.
→ 즉, 전체 데이터가 차지하는 비율 100%를 의미합니다.

---

### ✅ 요약

- y축 값 = 확률 밀도
$$
\text{확률 밀도} =
\frac{\text{구간의 빈도수}}{\text{전체 데이터 수} \times \text{구간 너비}}
$$

- 확률 밀도를 사용하면 히스토그램의 전체 면적이 1이 되도록 스케일링 됩니다.

---

### 원문 코드 실습 3

```python
#  파이썬 예시 코드 (히스토그램 + 확률 밀도)

import numpy as np
import matplotlib.pyplot as plt

# 1. 샘플 데이터 생성 (정규분포)
np.random.seed(42)
data = np.random.normal(loc=170, scale=10, size=100)

# 2. 히스토그램 계산 (density=False → 빈도수)
counts, bin_edges = np.histogram(data, bins=10, density=False)
print( 'counts:',counts)
print( 'bin_edges:',bin_edges)
print('data 갯수:',len(data))
print('-------------'*2)
# 3. 구간 너비 계산
bin_width = bin_edges[1] - bin_edges[0]

# 4. 확률 밀도 계산
density = counts / (len(data) * bin_width)
print( '도수 1인경우:', 1/(100*4.4720232885986775))
print("빈도수:", counts)
print("구간 너비:", bin_width)
print("확률 밀도:", density )
print('빈도수로 변환', ( density*bin_width)*len(data) )
print('구간너비X밀도', (density*bin_width).sum())
print('-------------'*2)

# 5. 히스토그램 그리기 (확률 밀도 적용)
plt.hist(data, bins=10, density=True, color='green',
          alpha=0.6, label='Histogram (Density)')
plt.xlabel("Height (cm)")
plt.ylabel("Probability Density")
plt.title("Histogram with Probability Density")

# 6. 정규분포 곡선 추가
x = np.linspace(min(data), max(data), 100)
from scipy.stats import norm
y = norm.pdf(x, loc=170, scale=10)
plt.plot(x, y, label='Normal PDF')

plt.legend()
plt.show()
```
