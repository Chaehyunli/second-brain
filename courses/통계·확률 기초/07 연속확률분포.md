## PDF, CDF

### 1. 확률 밀도 함수 (PDF)

* **정의**: 확률 밀도 함수는 **연속 확률 분포**에서 특정 값 주위의 구간에 값이 나올 가능성(**확률의 밀도**)을 나타냅니다.

* **목적**: 특정 구간에서 값이 나올 확률을 계산하는 데 사용됩니다.

* **특징**: 연속형 확률 변수의 경우, **특정 값 자체에 대한 확률은 0**입니다. 대신, 특정 범위에 걸친 확률을 구할 때 **적분**을 통해 계산합니다.

> 예를 들어, $f(x)$가 확률 밀도 함수라면:
$$
P(a \le X \le b) = \int_{a}^{b} f(x)dx
$$
이 식은 구간 $[a, b]$ 사이에서 값이 나올 확률을 의미합니다.
**예시:**

연속형 균일분포에서 $0$과 $10$ 사이의 확률 밀도 함수는 일정한 값(평평한 직선)입니다. 이때 특정 값 $5$에서의 확률 밀도는 일정하지만, $P(X = 5) = 0$이고, 특정 구간(예: $4$에서 $6$ 사이)의 확률을 계산해야 의미가 있습니다.

---

### 2. 적분을 이용한 거리 계산 예제

* 어떤 차가 시속 $60\text{ km}$로 $2$시간 동안 달렸을 때,
$$
\text{거리} = \int_{0}^{2} 60 \,dt = 60 \times (2 - 0) = 120\text{ km}
$$

* 여기서 **$60$은 속도**, **$dt$는 시간의 아주 작은 단위**를 의미합니다.
* **결과**는 **속도 $\times$ 시간 = 거리**의 원리가 적분을 통해 확인되는 것입니다.

### 2. 누적 분포 함수 (CDF)

* **정의**: 누적 분포 함수 $F(x)$는 확률 변수가 특정 값 $x$ **이하**의 값을 가질 확률을 나타냅니다.
* **목적**: $x$ 이하의 확률을 누적적으로 계산하는 데 사용됩니다. 즉, $X$가 주어진 값보다 작거나 같은 확률을 나타냅니다.

누적 분포 함수 $F(x)$는 다음과 같이 정의됩니다:
$$
F(x) = P(X \le x)
$$
이는 확률 밀도 함수 $f(t)$를 적분하여 얻을 수 있습니다:
$$
F(x) = \int_{-\infty}^{x} f(t)dt
$$

* **예시**: 연속형 균일분포에서 $0$과 $10$ 사이의 누적 분포 함수는 $0$에서 시작하여, 값이 증가할수록 누적 확률이 $1$에 가까워집니다. 예를 들어, $F(5)$는 $0$과 $5$ 사이의 값이 나올 확률을 의미합니다.

## 연속형 분포의 종류

### 1. 균일분포 (Continuous Uniform Distribution)

연속형 균일분포는 특정 구간 내의 **모든 값이 동일한 확률 밀도**를 가지는 분포입니다.

---

#### 1. 개념 및 특징

* **정의**: 주어진 구간 $[a, b]$ 내의 **모든 값에서 확률 밀도(Probability Density)가 일정한** 분포입니다.
* **특징**:
    * 구간 $[a, b]$ 밖의 확률 밀도는 **0**입니다.
    * 구간 $[a, b]$ 안에서는 확률 밀도가 $\frac{1}{b-a}$로 **일정**합니다.
* **표현**: 직사각형 모양의 그래프로 나타나며, 흔히 **직사각형 분포(Rectangular Distribution)**라고도 불립니다.

#### 2. 확률 밀도 함수 (PDF)

연속형 균일분포의 확률 밀도 함수 $f(x)$는 다음과 같습니다:

$$
f(x) = \begin{cases} \frac{1}{b-a} & \text{for } a \le x \le b \\ 0 & \text{otherwise} \end{cases}
$$

* **확률 계산**: 연속 분포이므로, 특정 값 $X=x$의 확률은 $0$입니다. 확률은 **특정 구간**을 **적분**하여 구합니다.
    $$P(c \le X \le d) = \int_{c}^{d} f(x) dx$$

#### 3. 예시

* **버스 도착 시간**: 버스가 $15$분 간격으로 운행될 때, 정류장에 도착한 승객이 버스를 기다리는 시간 $X$는 구간 $[0, 15]$ 사이의 모든 값을 가질 수 있으며, 이 구간 내에서 기다릴 확률 밀도는 모두 동일합니다.
    * 이 경우 $a=0$, $b=15$ 이므로, 확률 밀도는 $\frac{1}{15-0} = \frac{1}{15}$입니다.
* **랜덤 숫자 생성**: 컴퓨터 프로그램이 $0$과 $1$ 사이의 실수를 무작위로 생성할 때 ($a=0, b=1$), 이 범위 내의 어떤 특정 값 주위의 확률 밀도는 $\frac{1}{1-0}=1$로 모두 동일합니다.

만일 ($a=0, b=10$)에서는 확률 밀도 함수가 다음과 같이 $\frac{1}{10}$로 일정합니다:
$$
f(x) = \frac{1}{10-0} = \frac{1}{10} \quad \text{for } x \in [0, 10]
$$
즉, $0$에서 $10$ 사이의 어떤 값이 선택될 확률 밀도는 $\frac{1}{10}$로 일정합니다.

---

#### 확률 계산 공식 (균일분포)

연속형 균일분포에서 특정 구간 $[a, b]$에 값이 나올 확률은 다음과 같이 계산됩니다:

$$
P(a \le X \le b) = \frac{b-a}{\text{max} - \text{min}}
$$

**예시**: 우유의 양이 $0\text{ml}$에서 $10\text{ml}$ 사이에서 균일하게 분포할 때, $5\text{ml}$에서 $6\text{ml}$ 사이일 확률 계산은 다음과 같습니다.
* $\text{max} = 10$ (최댓값)
* $\text{min} = 0$ (최솟값)
* $a = 5, b = 6$ (우리가 구하려는 구간)

$$
P(5 \le X \le 6) = \frac{6-5}{10-0} = \frac{1}{10} = 0.1
$$
따라서, 우유의 양이 $5\text{ml}$에서 $6\text{ml}$ 사이에 있을 확률은 **$0.1$ ($10\%$)**입니다.

네, 이미지의 텍스트를 주피터 노트북 마크다운 형식으로 변환해 드립니다.

---

####  누적 분포 함수(CDF) 공식:

균일분포에서 구간 $[\text{min}, \text{max}]$ 사이의 누적 분포 함수는 다음과 같이 정의됩니다:

$$
F(x) = \frac{x - \text{min}}{\text{max} - \text{min}}
$$

여기서:

* $\text{min} = 0$ (최솟값)
* $\text{max} = 10$ (최댓값)
* $x$는 우리가 구하려는 특정 값입니다.

---

---

#### 🥛 $5\text{ml}$에서 $6\text{ml}$ 사이의 확률을 누적 분포 함수로 계산:

##### 1. $6\text{ml}$ 이하일 확률 $F(6)$:
균일분포의 누적 분포 함수(CDF) 공식 $F(x) = \frac{x - \text{min}}{\text{max} - \text{min}}$을 사용합니다. ($\text{min}=0$, $\text{max}=10$)

$$
F(6) = \frac{6 - 0}{10 - 0} = \frac{6}{10} = 0.6
$$

즉, 우유의 양이 $6\text{ml}$ 이하일 확률은 **$60\%$**입니다.

---

##### 2. $5\text{ml}$ 이하일 확률 $F(5)$:

$$
F(5) = \frac{5 - 0}{10 - 0} = \frac{5}{10} = 0.5
$$

즉, 우유의 양이 $5\text{ml}$ 이하일 확률은 **$50\%$**입니다.

---

#### 두 값의 차로 확률을 계산:

$$
P(5 \le X \le 6) = F(6) - F(5) = 0.6 - 0.5 = 0.1
$$

따라서, 누적 분포 함수를 사용해도 우유의 양이 $5\text{ml}$에서 $6\text{ml}$ 사이일 확률은 **$0.1 (10\%)$**로 계산됩니다.

---

### 원문 코드 실습 1

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import uniform
plt.rcParams['font.family'] ='Malgun Gothic'

# 우유의 양 범위 설정
min_value = 0
max_value = 10
x_values = np.linspace(min_value, max_value, 1000)
print('x_values', x_values)

# SciPy의 uniform 객체 생성 (균일분포)
# loc = min_value, scale = max_value - min_value
uniform_dist = uniform(loc=min_value, scale=max_value - min_value)
print( 'uniform_dist', uniform_dist)

# 확률 밀도 함수 (PDF)와 누적 분포 함수 (CDF) 값 계산
# uniform.pdf(x, loc=a, scale=b-a) -> R의 dunif(x, min=a, max=b)와 동일
pdf_values = uniform_dist.pdf(x_values) # PDF
print( 'pdf_values', pdf_values)

# uniform.cdf(x, loc=a, scale=b-a) -> R의 punif(x, min=a, max=b)와 동일
cdf_values = uniform_dist.cdf(x_values) # CDF

# 1. 확률 밀도 함수 (PDF) 그리기
plt.figure(figsize=(10, 5))

plt.subplot(1, 2, 1) # 1행 2열 중 첫 번째 영역
plt.plot(x_values, pdf_values, color="blue", linewidth=2)
plt.title("균일분포 PDF (0, 10)")
plt.xlabel("x")
plt.ylabel("밀도")
plt.ylim(0, 0.2)
plt.grid(True, linestyle='--', alpha=0.6)

# 2. 누적 분포 함수 (CDF) 그리기
plt.subplot(1, 2, 2) # 1행 2열 중 두 번째 영역
plt.plot(x_values, cdf_values, color="red", linewidth=2)
plt.title("균일분포 CDF (0, 10)")
plt.xlabel("x")
plt.ylabel("누적 확률")
plt.ylim(0, 1)
plt.grid(True, linestyle='--', alpha=0.6)

# 그래프 표시
plt.tight_layout() # 서브플롯 간의 간격 자동 조정
plt.show()
```

from scipy.stats import uniform

# 우유의 양 범위 설정

max_value = 10

# 결과 출력
print(f"3ml에서 7ml 사이의 확률: {probability}")

## 2.정규분포

###  정규분포(Normal Distribution) 설명

정규분포(Normal Distribution)는 **연속 확률 분포 중 가장 널리 사용되는 분포** 중 하나입니다. 정규분포는 **평균과 표준편차**를 이용해 특정 데이터가 어떻게 분포되는지를 나타냅니다.

---

#### 정규분포의 확률 밀도 함수

정규분포는 다음과 같은 식으로 표현됩니다:

$$f(x) = \frac{1}{\sqrt{2\pi\sigma^2}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

여기서:

* $\mu$는 **평균(Mean)**
* $\sigma$는 **표준편차(Standard Deviation)**

입니다.

---

### 정규분포 특징

평균이 다르고 표준편차도 다르지만,

* $N(50, 5^2)$ 에서 $50 \sim 55$까지의 넓이(확률)나
* $N(30, 2^2)$ 에서 $30 \sim 32$까지의 넓이(확률) 같아요!

즉, **정규분포**에서 $m$이 몇이든 $\sigma$가 몇이든!

$$P(m \le X \le m+k\sigma)$$

은 언제나 **동일합니다**!! ($k$는 정수)

---

정규분포의 **확률 밀도 함수(PDF: Probability Density Function)**는 특정 값 주위에서 확률이 얼마나 집중되어 있는지를 나타냅니다. 정규분포의 PDF는 평균과 표준편차를 기준으로 종 모양의 곡선을 가지며, 대부분의 값이 평균 근처에 분포합니다.

#### 정규분포 PDF 수식

정규분포의 확률 밀도 함수는 다음과 같이 정의됩니다.

$$
f(x) = \frac{1}{\sqrt{2\pi\sigma^2}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$

여기서:

* $\mu$는 평균 (mean),
* $\sigma$는 표준편차 (standard deviation),
* $f(x)$는 특정 값 $x$에서의 **확률 밀도**를 나타냅니다.

PDF는 특정 값 자체의 확률을 의미하는 것은 아니고, **특정 구간에서 값이 나올 가능성**을 나타냅니다. 이 값은 특정 구간에 대한 **적분**을 통해 구간 확률로 변환됩니다.

정규분포의 **누적 분포 함수(CDF: Cumulative Distribution Function)**는 특정 값 이하의 확률을 누적으로 계산하는 함수입니다. CDF는 확률 밀도 함수(PDF)를 **적분**한 결과로, **특정 값 $x$ 이하의 확률**을 나타냅니다.

#### 정규분포의 CDF 수식

정규분포의 누적 분포 함수는 다음과 같이 정의됩니다.

$$
F(x) = P(X \le x) = \int_{-\infty}^{x} f(t)dt
$$

여기서 $f(t)$는 정규분포의 확률 밀도 함수(PDF)입니다. 이 적분을 풀면, 표준 정규분포의 CDF는 다음과 같이 표현됩니다:

$$
F(x) = \frac{1}{2} \left[1 + \text{erf} \left(\frac{x - \mu}{\sigma\sqrt{2}}\right)\right]
$$

여기서:

* $\mu$는 평균 (mean),
* $\sigma$는 표준편차 (standard deviation),
* $\text{erf}(z)$는 **오차 함수**로, 특별한 함수로 정의된 값입니다.

정규분포의 CDF는 직접적인 해석이 어려워, 보통 **정규분포 테이블**이나 **계산 도구**를 사용하여 값을 계산합니다.

#### 2. 구간 확률 계산: PDF vs. CDF

정규분포에서 **PDF(확률 밀도 함수)**를 이용하여 70점에서 100점 사이의 확률을 계산하는 방법을 설명하겠습니다. PDF로 특정 구간의 확률을 계산하려면 해당 구간에서의 확률 밀도를 **적분**해야 합니다. 하지만 일반적으로 우리는 **적분 대신 누적 분포 함수(CDF)**를 사용하여 구간의 확률을 구합니다. PDF는 확률 밀도를 나타내는 함수이고, CDF는 누적 확률을 계산하는 함수입니다.

##### 1. PDF를 사용한 수식 전개

정규분포에서 특정 구간 $70 \le X \le 100$의 확률을 계산하기 위한 방법은 확률 밀도 함수(PDF)를 적분하는 것입니다:

$$
P(70 \le X \le 100) = \int_{70}^{100} f(x)dx
$$

여기서, 정규분포의 확률 밀도 함수 $f(x)$는 다음과 같이 정의됩니다:

$$
f(x) = \frac{1}{\sqrt{2\pi\sigma^2}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$

##### 3. 누적 분포 함수(CDF)를 이용한 계산

하지만 일반적으로 우리는 적분 대신 **누적 분포 함수(CDF)**를 사용하여 구간의 확률을 구합니다. CDF를 사용하면, 특정 구간의 확률을 다음과 같이 간단하게 계산할 수 있습니다:

$$
P(70 \le X \le 100) = F(100) - F(70)
$$

여기서 $F(x)$는 정규분포의 누적 분포 함수로, $x$ 값 이하의 누적 확률을 나타냅니다. 이를 통해 적분 계산을 간단하게 할 수 있습니다.

from scipy.stats import norm

# 평균과 표준편차 설정

# 구간 설정

print(f"70점에서 100점 사이의 확률: {probability:.4f}")

### 1. 정규분포의 특성:

---

정규분포는 평균을 중심으로 대칭적인 종 모양 곡선을 가집니다. 값이 평균에서 멀어질수록 확률 밀도가 급격히 감소하고, 대부분의 값이 평균 근처에 집중됩니다. 표준편차의 몇 배에 해당하는 구간이 어느 정도의 확률을 포함하는지 설명하면 다음과 같습니다:

- 1 표준편차 범위 내 (𝜇±1𝜎): 전체 값의 약 **68.27%**가 포함됩니다.
- 2 표준편차 범위 내 (𝜇±2𝜎): 전체 값의 약 **95.45%**가 포함됩니다.
- 3 표준편차 범위 내 (𝜇±3𝜎): 전체 값의 약 **99.73%**가 포함됩니다.
- 4 표준편차 범위 내 (𝜇±4𝜎): 전체 값의 **99.994%**가 포함됩니다.

2. 4 표준편차를 선택한 이유:
- ±4 표준편차는 거의 모든 데이터(99.994%)를 포함하는 범위입니다.
- 이 범위를 넘어가면 확률 밀도가 매우 작아져, 그리 큰 의미가 없어집니다. 따라서 ±4 표준편차를 설정하면 사실상 전체 분포를 시각화할 수 있게 됩니다.

결론:
4 표준편차 범위를 사용하는 이유는, 이 범위 내에서 정규분포의 거의 모든 값을 포함할 수 있기 때문입니다. 이를 통해 그래프에서 대부분의 확률 밀도를 볼 수 있게 됩니다.

### 원문 코드 실습 8

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm

# 평균과 표준편차 설정
mean_value = 100  # 평균
sd_value = 15     # 표준편차

# x 값 범위 설정 (평균에서 ±4 표준편차 범위로 설정)
# R의 seq()와 유사하게 일정한 간격의 배열 생성
x_values = np.linspace(mean_value - 4 * sd_value, mean_value + 4 * sd_value, 1000)

# 확률 밀도 함수 값 계산 (PDF)
# R의 dnorm() 함수는 Python의 norm.pdf() 함수로 대체
pdf_values = norm.pdf(x_values, loc=mean_value, scale=sd_value)

# 정규분포 곡선 그리기
plt.figure(figsize=(10, 6))

# 1. 정규분포 곡선 플롯
plt.plot(x_values, pdf_values, color="blue", linewidth=2, label="PDF 곡선")

# 2. 70점에서 100점 사이의 구간 채우기
lower_bound = 70
upper_bound = 100

# 채우기에 사용할 x 값 구간을 70에서 100 사이로 설정
x_fill = np.linspace(lower_bound, upper_bound, 1000)

# 해당 x 값에 대한 PDF 값 계산
y_fill = norm.pdf(x_fill, loc=mean_value, scale=sd_value)

# plt.fill_between() 함수를 사용하여 영역 채우기
# where: x가 70과 100 사이에 있을 때만 채우기
# alpha: 투명도 설정 (R의 rgb(1, 0, 0, 0.4)와 유사)
plt.fill_between(x_fill, y_fill,
                 color='red', alpha=0.4,
                 label=f'{lower_bound} ~ {upper_bound} 확률')


# 3. 평균 위치에 수직선 추가
# R의 abline(v=mean_value)
plt.axvline(x=mean_value, color="red", linestyle="--", linewidth=2, label=f"평균 $\mu$={mean_value}")

# 4. 그래프 설정 (제목, 라벨 등)
plt.title(f"정규분포 곡선 (평균 {mean_value}, 표준편차 {sd_value})\n{lower_bound} ~ {upper_bound}점 사이의 확률", fontsize=15)
plt.xlabel("점수", fontsize=12)
plt.ylabel("확률 밀도", fontsize=12)
plt.legend()
plt.grid(axis='y', alpha=0.5)
plt.show()
```
