# 08 표준정규분포

상위: [[courses/통계·확률 기초/index|통계·확률 기초]]

## 핵심
- 정규분포는 평균과 표준편차가 다른 분포를 Z-변환 $Z=(X-μ)/σ$으로 공통 척도에서 비교한다.
- 표준정규분포는 평균 0, 표준편차 1이며 Z값은 평균에서 몇 표준편차 떨어졌는지를 뜻한다.
- Python 배열을 표준화하고 정규분포 구간의 면적·확률을 해석한다.
