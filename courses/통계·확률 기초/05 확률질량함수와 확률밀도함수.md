# 05 확률질량함수와 확률밀도함수

상위: [[courses/통계·확률 기초/index|통계·확률 기초]]

## 핵심
- **PMF**는 이산 확률변수의 각 값에 직접 확률을 할당한다.
- **PDF**는 연속 확률변수의 밀도이며, 특정 한 점의 확률은 0이고 구간의 면적(적분)이 확률이다.
- 두 함수 모두 전체 확률 합 또는 전체 면적이 1이어야 한다.
