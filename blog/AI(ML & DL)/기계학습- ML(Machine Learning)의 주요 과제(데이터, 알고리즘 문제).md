# [기계학습] ML(Machine Learning)의 주요 과제(데이터, 알고리즘 문제)

## 원문

https://ch010104.tistory.com/17

## 핵심 요약

- **ML(Machine Learning)의 주요 과제** — 머신러닝(Machine Learning)은 다양한 문제를 해결하는 강력한 도구이지만, 몇 가지 주요 도전 과제가 존재함.
- **1. 데이터 관련 문제** — 머신러닝 모델은 일반적으로 많은 데이터를 필요.
- **2. 알고리즘 관련 문제** — 과대적합은 모델이 훈련 데이터에 지나치게 최적화되어 새로운 데이터(테스트 데이터)에서 성능이 저하되는 현상.
- **3. 테스트와 검증** — 머신러닝 모델의 성능을 평가하기 위해 데이터를 훈련셋(Training Set)과 테스트셋(Test Set)으로 분할.
