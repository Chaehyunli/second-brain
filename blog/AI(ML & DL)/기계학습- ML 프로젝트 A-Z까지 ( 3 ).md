# [기계학습] ML 프로젝트 A-Z까지 ( 3 )

## 원문

https://ch010104.tistory.com/63

## 핵심 요약

- **1. 데이터 준비** — housing: median_house_value 컬럼이 제거된 입력 데이터
- **2. 데이터 정제 (Data Cleaning)** — 결과: total_bedrooms 컬럼 자체가 존재하지 않음
- **3. 결측치 자동 채우기 (SimpleImputer 사용)** — ocean_proximity(텍스트)는 제외된 상태
- **5. 범주형 특성 다루기** — 대부분의 머신러닝 알고리즘은 숫자만을 다룰 수 있기 때문에, 범주형 특성의 텍스트 값을 숫자 값으로 변환해야함
