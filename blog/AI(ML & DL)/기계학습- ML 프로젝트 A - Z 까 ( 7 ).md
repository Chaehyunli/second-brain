# [기계학습] ML 프로젝트 A - Z 까 ( 7 )

## 원문

https://ch010104.tistory.com/73

## 핵심 요약

- **1. 왜 하이퍼파라미터 튜닝이 필요한가?** — 모델 학습에는 **하이퍼파라미터(Hyperparameter)**라는 설정값이 있음.
- **2. Grid Search (그리드 탐색)** — 하이퍼파라미터의 모든 조합을 체계적으로 탐색하여 최적 조합을 찾는 방식
- **3. Randomized Search (랜덤 탐색)** — 모든 조합을 탐색하지 않고 지정한 수만큼 랜덤하게 샘플링
- **4. 특성 중요도 분석 (Feature Importance)** — 튜닝된 모델을 바탕으로 어떤 특성이 예측에 중요한지 확인
