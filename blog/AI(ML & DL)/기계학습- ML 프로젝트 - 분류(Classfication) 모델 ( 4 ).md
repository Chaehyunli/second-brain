# [기계학습] ML 프로젝트 - 분류(Classfication) 모델 ( 4 )

## 원문

https://ch010104.tistory.com/90

## 핵심 요약

- 머신러닝 분류 문제는 단순히 두 개의 클래스를 구분하는 **이진 분류(binary classification)**에서 출발
- **1. 다중 클래스 분류란?** — 정의: 주어진 샘플이 3가지 이상의 클래스 중 어느 클래스에 속하는지를 예측하는 문제
- **2. 사이킷런의 다중 클래스 분류기** — → 이진 분류만 가능한 분류기를 사용하는 경우, 여러 개의 이진 분류기를 조합하여 다중 분류 문제를 해결해야 함
- **3. 이진 분류기를 활용한 다중 클래스 분류 전략** — 1) OvR (One-vs-Rest / One-vs-All)
