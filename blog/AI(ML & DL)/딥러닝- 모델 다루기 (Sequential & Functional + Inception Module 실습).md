# [딥러닝] 모델 다루기 (Sequential & Functional + Inception Module 실습)

## 원문

https://ch010104.tistory.com/170

## 핵심 요약

- **모델 생성: Sequential** — 정의: 하나의 입력과 하나의 출력을 가지며, Layer를 순차적으로 쌓아나가는 방식
- **모델 생성: Functional** — 개념: 입력이나 출력이 하나로 제한되지 않는 모델링 방식
- **분기 모델 (Branching Model)** — 개념: 하나의 입력을 두 개(이상)의 출력으로 분기하는 경우
- **병합 모델 (Merging Model)** — 개념: 두 개(이상)의 입력을 한 개의 출력으로 병합하는 경우
