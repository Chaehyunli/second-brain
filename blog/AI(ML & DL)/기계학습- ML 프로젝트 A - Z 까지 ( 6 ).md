# [기계학습] ML 프로젝트 A - Z 까지 ( 6 )

## 원문

https://ch010104.tistory.com/70

## 핵심 요약

- **1. 데이터 준비 과정 요약** — 결측치 처리, 로그 변환, 특성 비율 계산, 범주형 처리 등 포함된 preprocessing 파이프라인 생성
- **2. 1차 모델: 선형 회귀 (Linear Regression)** — 선택 이유: 간단한 기본 회귀 모델로 시작하기에 적합
- **3. 2차 모델: 결정 트리 회귀 (Decision Tree Regression)** — 선택 이유: 선형 모델보다 더 복잡한 비선형 관계도 학습 가능
- **4. 교차 검증 (Cross Validation) 도입** — 목적: 과대적합 여부를 확인하고 더 일반적인 성능 평가 수행
