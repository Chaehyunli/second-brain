# [네트워크] 라우팅 알고리즘 - 다익스트라

## 원문

https://ch010104.tistory.com/274

## 핵심 요약

- **1. 컨트롤 플레인(Control Plane) vs 데이터 플레인(Data Plane)** — 네트워크 장비(라우터)의 역할은 크게 두 가지 영역으로 나뉩니다.
- **① 라우터별 컨트롤 플레인 (Per-router Control Plane)** — 특징: 각 라우터가 독립적인 라우팅 알고리즘을 실행합니다.
- **② SDN 컨트롤 플레인 (Software-Defined Networking)** — 특징: 원격 컨트롤러(Remote Controller)라는 중앙 서버가 모든 결정을 내립니다.
- **라우팅의 목표** — 송신지부터 수신지까지 "좋은(Good)" 경로를 찾는 것입니다.
