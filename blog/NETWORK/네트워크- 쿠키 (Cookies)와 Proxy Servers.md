# [네트워크] 쿠키 (Cookies)와 Proxy Servers

## 원문

https://ch010104.tistory.com/239

## 핵심 요약

- **사용자/서버 상태 유지: 쿠키 (Cookies)** — 기본적으로 HTTP는 '비상태(Stateless)' 프로토콜
- **웹 캐시: 프록시 서버 (Web Caches / Proxy Servers)** — 목표: 기점 서버(Origin Server)를 거치지 않고 클라이언트의 요청을 충족시키는 것입니다.
