## 핵심 요약

- GCP VPC(Virtual Private Cloud)는 Google Cloud Platform에서 제공하는 가상 네트워크 서비스
- **주요 기능** — VPC 내에서 IP 주소 범위를 정의하고, 리소스를 논리적으로 분리할 수 있음
- **요약** — GCP VPC는 클라우드 환경에서 네트워크를 유연하고 안전하게 관리할 수 있도록 도와주는 중요한 서비스
