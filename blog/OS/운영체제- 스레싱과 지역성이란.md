# [운영체제] 스레싱과 지역성이란??

## 원문

https://ch010104.tistory.com/88

## 핵심 요약

- **1. 프레임 할당 방식** — 메모리는 일정 크기의 프레임(Frame) 단위로 나뉘며, 운영체제는 각 프로세스에 이 프레임을 할당
- **2. 스레싱(Thrashing)이란?** — 프로세스가 실행보다 페이지 교체에 더 많은 시간을 소비하는 상태
- **3. 지역성(Locality)의 원리** — 1) 지역성 원칙(Principle of Locality)
- **4. 작업집합(Working Set) 모델** — 지역성을 기반으로 각 프로세스에 필요한 **최소한의 페이지 집합(Δ 시간 동안 참조된 페이지 집합)**을 정의
