# [운영체제] 프로세스 종료와 통신

## 원문

https://ch010104.tistory.com/39

## 핵심 요약

- **1. 프로세스 종료 (Process Termination)** — 종료 시 exit() 시스템 호출을 통해 운영체제에 종료 요청
- **3. 공유 메모리(Shared Memory)와 메시지 전달 (Message Passing)** — 상호 협조 프로세스에서 여러 프로세스가 정보를 어떻게 공유할까?
- **4. 직접 통신 vs 간접 통신** — 네트워크에서의 통신이 아닌, 하나의 컴퓨터 내에서 P1과 P2 프로세스간의 통신임
- **5. 동기화 방식** — 위와 같이 메시지를 전송(send)을 했는데 수신(receive)를 바로 하지 않을 수도 있음.
