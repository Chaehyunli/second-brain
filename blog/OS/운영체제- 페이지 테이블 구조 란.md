# [운영체제] 페이지 테이블 구조 란??

## 원문

https://ch010104.tistory.com/74

## 핵심 요약

- **1. 페이징(Paging) 기본 개념** — 현대 컴퓨터는 32비트~64비트의 매우 큰 논리 주소 공간을 사용
- **2. 계층적 페이징(Hierarchical Paging)** — 전체 페이지 테이블을 메인 메모리에 연속으로 할당하는 대신, 페이지 테이블 자체를 페이지화하여 여러 단계로 나눔.
- **3. 해시 기반 페이지 테이블 (Hashed Page Table)** — 주소 공간이 32비트 이상으로 매우 큰 경우에 사용
- **4. 역 페이지 테이블 (Inverted Page Table)** — 각 항목에는 어떤 프로세스의 어떤 페이지가 저장되어 있는지 기록
