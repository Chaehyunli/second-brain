# [운영체제] 프로세스(Process) 란?

## 원문

https://ch010104.tistory.com/23

## 핵심 요약

- **1. 프로세스란?** — 프로세스(Process) = 실행 중인 프로그램
- **2. 실행 파일의 구조** — 실행 후 메모리 구조 (프로세스 주소 공간) sample.c를 컴파일하면 sample.exe의 실행 파일이 생성됨!!
- **3. 프로세스의 구성 요소** — CS, PC, DS, SS 등의 레지스터에 프로세스의 각각에 해당되는 주소가 저장!!
- **4. PCB(Process Control Block)란?** — 운영체제가 프로세스를 관리하기 위해 유지하는 데이터 구조
