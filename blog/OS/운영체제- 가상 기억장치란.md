# [운영체제] 가상 기억장치란??

## 원문

https://ch010104.tistory.com/77

## 핵심 요약

- **1. 가상 기억장치란?** — 프로그램 전체가 메모리에 한꺼번에 올라오지 않아도 되는 경우가 많습니다.
- **2. 요구 페이징 (Demand Paging)** — 요구 페이징은 필요한 페이지가 실제 참조될 때 메모리에 로딩하는 방식
- **3. 페이지 테이블과 유효-무효 비트** — 유효(valid) 비트: 1 → 메모리에 적재되어 있음
- **4. 페이지 부재 처리 과정** — 페이지에 대한 참조가 첫번째 참조라면 페이지 부재가 발생되고 운영체제에게 제어가 넘어감
