## 핵심 요약

- 이전에 말했듯이 CPU의 모드에는 사용자 모드와 커널모드가 있음.
- **1. 시스템 호출(System Call) 이란?** — 여기서 응용 프로그램이란, 사용자 모드에서 작업을 하는 C프로그램을 예로 들 수 있음.
- **2. 시스템 호출(System Call)의 종류** — 속성 획득(get attribute): 프로세스의 속성 정보 조회.
