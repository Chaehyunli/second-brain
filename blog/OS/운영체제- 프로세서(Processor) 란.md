# [운영체제] 프로세서(Processor) 란?

## 원문

https://ch010104.tistory.com/9

## 핵심 요약

- **📌 프로세서란?** — **프로세서(Processor)**는 컴퓨터의 두뇌 역할을 하는 핵심 부품으로, 연산을 수행하고 명령을 제어하는 역할을 함.
- **1. 프로세서의 기본 구조** — 프로세서는 크게 **제어 장치(Control Unit), 연산 장치(ALU), 레지스터(Register), 버스(Bus) **로 구성됩니다.
- **2. 프로세서의 동작 과정** — 프로세서는 명령어를 가져오고(페치, Fetch), 해석하고(디코드, Decode), 실행하는(Execute) 과정을 반복
- **1) 프로세서의 6가지 기본 기능** — 메모리에서 명령어를 읽기 (Instruction Fetch)
