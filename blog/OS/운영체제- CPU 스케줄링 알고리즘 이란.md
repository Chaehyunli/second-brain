# [운영체제] CPU 스케줄링 알고리즘 이란??

## 원문

https://ch010104.tistory.com/56

## 핵심 요약

- FCFS (First-Come First-Served)
- **1. FCFS (First-Come First-Served)** — 프로세스: P1(24), P2(3), P3(3) 도착 순서: P1, P2, P3
- **2. SJF (Shortest Job First)** — 다음 CPU 버스트가 가장 짧은 프로세스를 먼저 실행
- **3. Priority 스케줄링** — 프로세스마다 우선순위(정수)를 부여하여 CPU를 할당 - 이는 스케줄링 알고리즘이 아닌, 우선순위를 부여하여 CPU를 할당하는 방식을 말함.
