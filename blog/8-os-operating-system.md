# [운영체제] 운영체제(OS, Operating System)란?

> 원문: https://ch010104.tistory.com/8

## 본문

1. 정의 운영체제(OS)는 컴퓨터 하드웨어와 소프트웨어를 관리하고, 사용자와 컴퓨터 간의 인터페이스 역할을 하는 시스템 소프트웨어   즉, 컴퓨터 사용자와 컴퓨터 하드웨어 사이의 매개체 역할을 하는 프로그램!! 운영체제만을 가지고 매개체 역할을 하는 것이 아닌, 응용 프로그램을 사용하여 매개체 역할을 수행함.   2. 목적 1) 사용자 관점에서의 목적 (User view)  사용자에게 프로그램을 수행할수있는 환경을 제공 컴퓨터 시스템을 편리하게 이용할 수 있게 해줌  2) 컴퓨터 하드웨어 관점에서의 목적(System view)  컴퓨터 하드웨어를 효율적으로 이용, 관리하기 위해 특히, 다중 사용자컴퓨터인경우 -> ex) 서버  3. 주요 기능 1) 프로세스 관리 2) 메모리 관리 3) 저장장치 관리 4) 파일 시스템 5) 입출력 장치 관리
