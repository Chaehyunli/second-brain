# [모바일 프로그래밍]  LinearLayout 안드로이드 레이아웃

## 원문

https://ch010104.tistory.com/149

## 핵심 요약

- **1. 레이아웃(Layout)이란?** — - 레이아웃은 내부에 다양한 위젯(버튼, 텍스트뷰 등)을 담는 일종의 컨테이너
- **2. LinearLayout의 핵심 속성** — - LinearLayout을 다루기 위해 꼭 알아야 할 주요 속성들이 있음
- **3. LinearLayout 사용법** — - orientation 속성은 vertical(수직)과 horizontal(수평), 두 가지 값을 가짐
- **4. 복잡한 화면을 위한 LinearLayout 활용** — - 더 복잡한 화면은 LinearLayout 안에 또 다른 LinearLayout을 넣어 구성할 수 있음
