# [모바일 프로그래밍] 메뉴 (Option Menu & Context Menu)

## 원문

https://ch010104.tistory.com/158

## 핵심 요약

- **옵션 메뉴 (Option Menu)** — 옵션 메뉴는 액티비티의 주 메뉴로, 보통 앱 바(App Bar)에 표시
- **컨텍스트 메뉴 (Context Menu)** — - 컨텍스트 메뉴는 특정 위젯(버튼, 텍스트 뷰 등)을 길게 클릭(long-click)했을 때 나타나는 메뉴
