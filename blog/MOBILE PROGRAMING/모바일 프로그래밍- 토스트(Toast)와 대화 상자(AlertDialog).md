# [모바일 프로그래밍] 토스트(Toast)와 대화 상자(AlertDialog)

## 원문

https://ch010104.tistory.com/164

## 핵심 요약

- **1. 토스트 (Toast)** — - 토스트는 화면에 잠시 나타났다가 사라지는 간단한 메시지
- **2. 대화상자 (AlertDialog)** — - 대화상자의 기본은 AlertDialog이며, 제목, 내용, 버튼 영역으로 구분됨.
- **3. 목록 형태의 대화상자** — - 목록을 제공하고 사용자의 선택을 받는 대화상자를 만들 수 있음.
- **4. 대화상자 닫기 옵션** — setCancelable(false): 기기의 뒤로가기 버튼으로 대화상자가 닫히는 것을 방지함.
