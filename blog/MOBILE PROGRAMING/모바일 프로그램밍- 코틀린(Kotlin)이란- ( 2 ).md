# [모바일 프로그램밍] 코틀린(Kotlin)이란? ( 2 )

## 원문

https://ch010104.tistory.com/125

## 핵심 요약

- **1. 기초 타입 배열 (Primitive Type Arrays)** — 코틀린에서는 기초 타입의 배열을 더 효율적으로 다루기 위해 전용 배열 클래스를 제공
- **2. 컬렉션 타입 (Collection Types)** — List: 순서가 있는 데이터 집합, 중복 허용
- **3. 조건문과 반복문** — 코틀린의 if-else는 표현식으로 사용 가능하여 결괏값을 반환
- **4. 클래스와 생성자** — 주 생성자 (Primary Constructor)
