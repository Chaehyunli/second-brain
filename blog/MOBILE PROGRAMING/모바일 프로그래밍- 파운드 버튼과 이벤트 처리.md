# [모바일 프로그래밍] 파운드 버튼과 이벤트 처리

## 원문

https://ch010104.tistory.com/141

## 핵심 요약

- **1. 선택의 상태를 담다: 컴파운드 버튼 (CompoundButton)** — 선택/해제 상태를 가질 수 있는 버튼들의 상위 클래스
- **2. XML과 코드를 연결하는 다리: 뷰 바인딩 (View Binding)** — - 뷰 바인딩은 XML 레이아웃 파일에 정의된 뷰 객체들을 코드에서 간편하게 사용하기 위한 기능
- **3. 사용자의 동작에 반응하기: 뷰 이벤트 처리** — - 이벤트 처리는 사용자의 특정 행동(클릭, 상태 변경 등)에 따라 앱이 반응하도록 만드는 과정
