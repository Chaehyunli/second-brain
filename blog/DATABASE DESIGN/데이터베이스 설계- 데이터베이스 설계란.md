# [데이터베이스 설계] 데이터베이스 설계란?

## 원문

https://ch010104.tistory.com/114

## 핵심 요약

- **🚀 데이터베이스는 왜 필요할까? (Purpose of Database Systems)** — - 과거에는 모든 데이터를 파일 시스템 위에 직접 저장하고 관리
- **🔧 데이터베이스의 핵심 개념: 추상화와 독립성** — - DBMS는 사용자에게 데이터의 복잡한 물리적 구조를 숨기고, 간결하고 일관된 뷰(View)를 제공하는 것
- **💻 데이터베이스와 소통하는 언어: DDL & DML** — 데이터 정의 언어 (DDL - Data Definition Language)
- **🏛️ 데이터베이스의 내부 구조와 아키텍처** — 데이터베이스 엔진 (Database Engine)
