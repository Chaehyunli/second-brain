# [데이터베이스 설계] 동시성 제어

## 원문

https://ch010104.tistory.com/187

## 핵심 요약

- **동시성 제어 기본 (Prologue)** — 동시성 제어는 트랜잭션의 기본 속성인 고립성(Isolation)을 보장하기 위해 필요
- **락 기반 프로토콜 (Lock-Based Protocols)** — 락(Lock)은 데이터 항목에 대한 동시 접근을 제어하는 메커니즘
- **2단계 락 프로토콜 (Two-Phase Locking Protocol, 2PL)** — 충돌 직렬 가능성(Conflict-serializability)을 보장하는 프로토콜
- **락 구현 (Implementation)** — 락 관리자 (Lock Manager): 별도 프로세스로 구현.
