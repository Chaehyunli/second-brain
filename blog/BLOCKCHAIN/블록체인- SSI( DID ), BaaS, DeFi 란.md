# [블록체인] SSI( DID ), BaaS, DeFi 란??

## 원문

https://ch010104.tistory.com/76

## 핵심 요약

- **1. SSI (Self-Sovereign Identity): 자기주권 신원** — SSI는 사용자가 제3자의 개입 없이 자신의 디지털 신원을 직접 소유하고 관리할 수 있도록 하는 모델
- **2. BaaS (Blockchain as a Service): 서비스형 블록체인** — BaaS는 클라우드 기반의 블록체인 서비스로, 복잡한 인프라 없이도 블록체인 기술을 빠르게 도입할 수 있게 해주는 플랫폼
- **3. DeFi (Decentralized Finance): 탈중앙화 금융** — DeFi는 중앙 기관 없이 스마트 컨트랙트를 통해 은행, 증권, 보험과 같은 금융 서비스를 블록체인상에서 제공하는 시스템
