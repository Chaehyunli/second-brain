## 핵심 요약

- **🐍 파이썬 (Python)** — 파이썬은 문자열 객체 안에 자체적인 판별 메서드가 내장되어 있어 매우 편리합니다.
- **☕ 자바 (Java)** — 자바의 String 클래스에는 isdigit() 같은 단일 메서드가 없어서 보통 정규표현식을 사용합니다.
