## 구현 절차·검증·주의점

### 1. 비트마스킹을 왜 쓸까요?

압도적인 속도: CPU가 가장 빠르게 처리할 수 있는 비트 단위 연산자(AND, OR, XOR 등)를 사용하므로 수행 시간이 O(1)에 가깝습니다.

최소한의 메모리: 단 하나의 정수형 변수(int는 32개, long은 64개)로 수십 개의 상태(True/False) 또는 집합의 원소 포함 여부를 표현할 수 있습니다.

간결한 집합 연산: 합집합, 교집합, 여집합 등의 집합 연산을 단 한 줄의 비트 연산으로 끝낼 수 있습니다.

### 3. 핵심 비트마스킹 연산 공식 (Cheat Sheet)

정수 S를 집합(Set)으로 생각하고, $i$번째 비트가 존재하면 $i$가 집합에 포함되어 있음을 뜻한다고 가정합니다. (0번째 비트가 첫 번째 원소)

### ① 원소 추가 (SET): $i$번째 비트를 1로 만들기

이미 있으면 그대로 두고, 없으면 1을 채워 넣습니다.

공식: S | (1 << i)

```text
int S = 0; // 공집합 (0000)
S = S | (1 << 3); // 3번 원소 추가 -> (1000) -> 10진수 8
```

비트 연산 과정:

```text
S      (0000) :  0  0  0  0
  1 << 3 (1000) :  1  0  0  0   (| 연산)
------------------------------
  결과 S (1000) :  1  0  0  0   -> 10진수 8
```

> 원문 코드가 길어 이 노트에서는 앞부분만 보존했습니다. 전체는 원문에서 확인합니다.

### ② 원소 삭제 (CLEAR): $i$번째 비트를 0로 만들기

이미 0이면 그대로 두고, 1이면 0으로 지웁니다.

공식: S & ~(1 << i)

```text
int S = 13; // (1101) -> 0, 2, 3번 원소가 포함된 상태
S = S & ~(1 << 2); // 2번 원소 지우기 -> (1001) -> 10진수 9
```

비트 연산 과정:

```text
S       (1101) :  1  1  0  1
  ~(1<<2) (1011) :  1  0  1  1   (& 연산)
-------------------------------
  결과 S  (1001) :  1  0  0  1   -> 10진수 9
```

> 원문 코드가 길어 이 노트에서는 앞부분만 보존했습니다. 전체는 원문에서 확인합니다.

### ③ 원소 확인 (GET): $i$번째 비트가 1인지 확인하기

특정 자리에 비트가 켜져 있는지 참/거짓으로 판별합니다.

공식: (S & (1 << i)) != 0

[케이스 A: 존재하는 원소 확인]

```text
int S = 9; // (1001)
boolean hasElement3 = (S & (1 << 3)) != 0; // true (8 != 0)
```

비트 연산 과정:

```text
S      (1001) :  1  0  0  1
  1 << 3 (1000) :  1  0  0  0   (& 연산)
------------------------------
  결과   (1000) :  1  0  0  0   -> 0이 아니므로 true
```

> 원문 코드가 길어 이 노트에서는 앞부분만 보존했습니다. 전체는 원문에서 확인합니다.

[케이스 B: 존재하지 않는 원소 확인]

```text
int S = 9; // (1001)
boolean hasElement1 = (S & (1 << 1)) != 0; // false (0 != 0)
```

비트 연산 과정:

```text
S      (1001) :  1  0  0  1
  1 << 1 (0010) :  0  0  1  0   (& 연산)
------------------------------
  결과   (0000) :  0  0  0  0   -> 0이므로 false
```

> 원문 코드가 길어 이 노트에서는 앞부분만 보존했습니다. 전체는 원문에서 확인합니다.

### ④ 원소 토글 (TOGGLE): $i$번째 비트 뒤집기

있으면 없애고, 없으면 새로 켭니다.

공식: S ^ (1 << i)

[케이스 A: 켜져 있는 원소 토글 (끄기)]

```text
int S = 9; // (1001)
S = S ^ (1 << 3); // 3번 원소 뒤집기 -> 켜져 있으므로 꺼짐 -> (0001) -> 10진수 1
```

비트 연산 과정:

```text
S      (1001) :  1  0  0  1
  1 << 3 (1000) :  1  0  0  0   (^ 연산)
------------------------------
  결과 S (0001) :  0  0  0  1   -> 10진수 1
```

> 원문 코드가 길어 이 노트에서는 앞부분만 보존했습니다. 전체는 원문에서 확인합니다.

[케이스 B: 꺼져 있는 원소 토글 (켜기)]

```text
int S = 9; // (1001)
S = S ^ (1 << 1); // 1번 원소 뒤집기 -> 꺼져 있으므로 켜짐 -> (1011) -> 10진수 11
```

비트 연산 과정:

```text
S      (1001) :  1  0  0  1
  1 << 1 (0010) :  0  0  1  0   (^ 연산)
------------------------------
  결과 S (1011) :  1  0  1  1   -> 10진수 11
```

> 원문 코드가 길어 이 노트에서는 앞부분만 보존했습니다. 전체는 원문에서 확인합니다.

### ⑤ 모든 원소 비우기 (CLEAR ALL)

공식: S = 0

### ⑥ 가득 찬 집합 만들기 (FULL SET): $N$개의 원소를 모두 채우기

공식: (1 << N) - 1

```text
int N = 4; // 0, 1, 2, 3번 자리를 모두 1로 채우고 싶을 때
int fullSet = (1 << N) - 1; // 2^4 - 1 = 15 -> (1111)
```

비트 연산 과정:

```text
1 << 4 (10000) :  1  0  0  0  0
  - 1    (01111) :  0  1  1  1  1   (뺄셈 연산)
---------------------------------
  결과   (01111) :  0  1  1  1  1   -> 10진수 15 (0~3번 비트가 모두 1로 채워짐)
```

> 원문 코드가 길어 이 노트에서는 앞부분만 보존했습니다. 전체는 원문에서 확인합니다.

### 4. 실전 최적화 테크닉 (Advanced Bit Tricks)

코딩 테스트나 심화 문제 해결에서 가장 강력한 무기가 되는 연산 패턴들입니다.

### 💡 2의 거듭제곱 여부 판별하기

어떤 수 $x$가 $2^n$ ($2, 4, 8, 16, \dots$) 형태의 숫자인지 $O(1)$로 검사합니다.

공식: (x & (x - 1)) == 0 && x > 0

```text
int x = 8; // (1000)
// (1000) & (0111) == 0 -> true (2의 거듭제곱 맞음)
```

### 💡 가장 오른쪽에 있는 켜진 비트(1)만 찾기 (LSB)

이진수에서 가장 처음으로 만나는 1의 자릿수 값을 얻습니다. (예: 0110 -> 0010)

공식: x & -x

```text
int x = 12; // (1100)
int lsb = x & -x; // (1100) & (0100) = (0100) -> 4
```

### 💡 가장 오른쪽에 있는 꺼진 비트(0)만 찾기

이진수에서 가장 처음으로 만나는 0의 자릿수 값을 얻습니다. (예: 1011 -> 0100)

공식: ~x & (x + 1)

```text
int x = 11; // (1011)
int firstZero = ~x & (x + 1); // (0100) & (1100) = (0100) -> 4
```

### 💡 가장 오른쪽에 있는 켜진 비트(1)를 제거하기

공식: x & (x - 1)

```text
int x = 13; // (1101)
x = x & (x - 1); // (1101) & (1100) = (1100) -> 12 (가장 오른쪽 1이 사라짐)
```

### 5. 자바 내장 비트 메서드 백과사전

자바의 Integer 및 Long 클래스에는 비트 연산을 매우 편하게 해주는 최적화된 내장 메서드가 이미 구현되어 있습니다. 가독성을 위해 직접 비트 연산 기호를 적는 대신 이를 사용하는 것이 좋습니다.

```text
int x = 22; // 2진수: 0000 0000 0000 0000 0000 0000 0001 0110

// ① 켜진 비트(1)의 총 개수 세기
int count = Integer.bitCount(x);
System.out.println("1의 개수: " + count); // 출력: 3

// ② 뒤에서부터 연속된 0의 개수 세기 (가장 처음 등장하는 1의 인덱스 확인용)
int trailingZeros = Integer.numberOfTrailingZeros(x);
System.out.println("하위 연속된 0의 개수: " + trailingZeros); // 출력: 1

// ③ 앞에서부터 연속된 0의 개수 세기 (전체 자릿수 중 남은 공간 확인용)
int leadingZeros = Integer.numberOfLeadingZeros(x);
System.out.println("상위 연속된 0의 개수: " + leadingZeros); // 출력: 27 (32비트 기준)

// ④ 가장 왼쪽(최상위)에 켜진 비트값만 남기고 나머지 0 만들기
int highestOne = Integer.highestOneBit(x);
System.out.println("최상위 비트 값: " + highestOne); // 출력: 16 (10000)

// ⑤ 가장 오른쪽(최하위)에 켜진 비트값만 남기고 나머지 0 만들기 (x & -x 동일 효과)
int lowestOne = Integer.lowestOneBit(x);
System.out.println("최하위 비트 값: " + lowestOne); // 출력: 2 (00010)
```

### 6. 전체 종합 실습 코드

비트마스킹 개념을 총망라하여 실제 자바로 테스트할 수 있는 실행 가능한 종합 예제 코드입니다.

```java
public class BitmaskMaster {
    public static void main(String[] args) {
        // 1. 비트 집합 생성 (초기 상태: 빈 집합)
        int mySet = 0;
        System.out.println("초기 상태: " + Integer.toBinaryString(mySet));

        // 2. 원소 추가: 1, 3, 5 추가
        mySet |= (1 << 1);
        mySet |= (1 << 3);
        mySet |= (1 << 5);
        System.out.println("1, 3, 5 추가 후: " + Integer.toBinaryString(mySet)); // 101010 (42)

        // 3. 원소 포함 여부 확인: 3과 4 확인
        boolean hasThree = (mySet & (1 << 3)) != 0;
        boolean hasFour = (mySet & (1 << 4)) != 0;
        System.out.println("3번 포함 여부: " + hasThree); // true
        System.out.println("4번 포함 여부: " + hasFour);  // false

        // 4. 원소 삭제: 3번 원소 제거
        mySet &= ~(1 << 3);
        System.out.println("3번 삭제 후: " + Integer.toBinaryString(mySet)); // 100010 (34)

        // 5. 원소 토글: 5번 제거 및 2번 활성화
        mySet ^= (1 << 5); // 5번 꺼짐
        mySet ^= (1 << 2); // 2번 켜짐
        System.out.println("토글 후 상태: " + Integer.toBinaryString(mySet)); // 000110 (6)

        // 6. 2의 거듭제곱 판별 실습
        int val1 = 16;
        int val2 = 18;
        System.out.println(val1 + "은 2의 거듭제곱인가? " + ((val1 & (val1 - 1)) == 0)); // true
        System.out.println(val2 + "은 2의 거듭제곱인가? " + ((val2 & (val2 - 1)) == 0)); // false
    }
}
```
