# [백준(Java)] 13241. 최소공배수 (유클리드 호제법)

## 원문

https://ch010104.tistory.com/30

## 핵심 요약

- **문제** — 정수 B에 0보다 큰 정수인 N을 곱해 정수 A를 만들 수 있다면, A는 B의 배수이다.
- **입력** — 한 줄에 두 정수 A와 B가 공백으로 분리되어 주어진다.
- **내 풀이** — 입력으로 주어진 두 수의 최소공배수를 출력하는 간단한 프로그램이다.
- **결론 및 정리** — 두 정수 a, b (a ≥ b)의 최대공약수 GCD(a, b)는 GCD(b, a % b) 와 같다는 성질을 반복해서 b가 0이 될 때까지 계산하는 알고리즘.
