# [알고리즘] 정렬 알고리즘이란?(Merge Sort, Heap Sort, Quick Sort)

## 원문

https://ch010104.tistory.com/118

## 핵심 요약

- **1. 병합 정렬 (Merge Sort)** — 병합 정렬은 말 그대로 "나누고 합치는" 과정을 통해 전체를 정렬하는 방식
- **2. 힙 정렬(Heap Sort)** — - 항상 부모 노드가 자식 노드보다 큰 값을 가지는(최대 힙 기준) 특징
- **3. 퀵 정렬 (Quick Sort):** — - 퀵 정렬은 이름 그대로 평균적으로 매우 빠른 성능을 자랑하는 정렬 알고리즘 - 병합 정렬과 달리 추가적인 메모리 공간을 거의 사용하지 않는다는 큰 장점
