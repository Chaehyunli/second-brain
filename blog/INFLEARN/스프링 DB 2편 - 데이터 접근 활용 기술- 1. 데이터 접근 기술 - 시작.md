# [스프링 DB 2편 - 데이터 접근 활용 기술] 1. 데이터 접근 기술 - 시작

## 핵심 요약

- **1. 데이터 접근 기술 진행 방식 소개** — 이번 강의에서는 메모리 저장소로 동작하던 상품 관리 프로젝트에 데이터 접근 기술을 하나씩 적용한다.
- **SQL Mapper와 ORM** — SQL Mapper: 개발자가 SQL을 작성하면 SQL 결과를 객체로 매핑한다.
- **2. 프로젝트 설정과 메모리 저장소** — 기존 MVC 1편의 상품 관리 프로젝트를 기반으로 itemservice-db-start 프로젝트를 사용한다.
- **스프링 부트 3.0 주의 사항** — javax 패키지는 jakarta로 변경해야 한다.
