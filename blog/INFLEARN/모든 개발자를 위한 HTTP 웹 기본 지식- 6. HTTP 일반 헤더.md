# [모든 개발자를 위한 HTTP 웹 기본 지식] 6. HTTP 일반 헤더

## 원문

https://ch010104.tistory.com/249

## 핵심 요약

- **1. HTTP 헤더 개요** — 형식: field-name ":" OWS field-value OWS (field-name은 대소문자 구분 없음)
- **2. HTTP 바디와 헤더의 변화 (RFC2616 → RFC7230)** — 과거 (RFC2616): 엔티티(Entity)라는 용어 사용.
- **3. 표현(Representation) 헤더** — 표현 헤더는 전송과 응답 모두에서 사용됩니다.
- **4. 협상(Content Negotiation)** — 클라이언트가 선호하는 표현을 서버에 요청하는 것으로, 요청시에만 사용합니다.
