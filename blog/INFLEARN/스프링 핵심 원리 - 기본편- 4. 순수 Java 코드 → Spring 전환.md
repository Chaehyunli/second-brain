# [스프링 핵심 원리 - 기본편] 4. 순수 Java 코드 → Spring 전환

## 원문

https://ch010104.tistory.com/222

## 핵심 요약

- **1. 설정 정보의 변화 (AppConfig)** — 개발자가 직접 메서드를 호출해 객체를 생성함.
- **2. 관리 주체의 변화 (IoC 컨테이너 등장)** — ApplicationContext: 우리가 만든 AppConfig를 읽어서 객체들을 담아두는 **'거대한 창고'**입니다.
- **"코드가 왜 더 복잡해 보일까?" (Before vs After)** — 구분 순수 자바 (Before) 스프링 컨테이너 (After)
- **1. 싱글톤 컨테이너 (Singleton)** — 자바 방식: 누군가 appConfig.memberService()를 100번 호출하면 (설계에 따라 다르지만) 객체가 계속 생성될 위험이 있습니다.
