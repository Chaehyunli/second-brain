# [스프링 DB 2편 - 데이터 접근 활용 기술] 2. 데이터 접근 기술 - 스프링 JdbcTemplate

## 원문

https://ch010104.tistory.com/301

## 핵심 요약

- **1. JdbcTemplate 소개와 설정** — SQL을 직접 사용하는 경우 스프링이 제공하는 JdbcTemplate은 좋은 선택지다.
- **build.gradle** — org.springframework.boot:spring-boot-starter-jdbc를 추가하면 JdbcTemplate이 포함된 spring-jdbc가 함께 추가된다.
- **2. JdbcTemplate 적용 1 - 기본** — ItemRepository 인터페이스를 기반으로 JdbcTemplate 구현체를 추가한다.
- **핵심 메서드와 코드 흐름** — JdbcTemplateItemRepositoryV1은 인터페이스는 그대로 두고 구현 기술만 JDBC 직접 사용에서 JdbcTemplate으로 교체한 코드다.
