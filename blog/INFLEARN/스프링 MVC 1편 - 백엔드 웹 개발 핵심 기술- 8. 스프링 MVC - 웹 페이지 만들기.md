## 핵심 요약

- **1. 프로젝트 생성** — 스프링 부트 스타터 사이트(https://start.spring.io)를 통해 프로젝트를 생성한다.
- **Item - 상품 객체** — @Data: Lombok의 기능을 사용하여 Getter, Setter, ToString 등을 자동으로 생성한다.
- **4. 정적 상품 서비스 HTML (Static)** — 백엔드 로직 완성 전, 웹 퍼블리셔가 부트스트랩을 활용해 제공한 HTML 파일들이다.
- **BasicItemController** — @RequiredArgsConstructor: final 키워드가 붙은 멤버 변수의 생성자를 자동으로 생성한다.
