# [스프링 입문] 2.MVC 템플릿 엔진 vs API 방식

## 원문

https://ch010104.tistory.com/202

## 핵심 요약

- **1. MVC와 템플릿 엔진 (Model, View, Controller)** — 사용자가 보낸 파라미터를 받아 서버에서 HTML을 동적으로 가공해 응답하는 방식입니다.
- **예시 코드** — View (resources/templates/hello-template.html):HTML
- **동작 원리** — 브라우저에서 localhost:8080/hello-mvc?name=spring으로 요청을 보냅니다.
- **2. API 방식 - 문자 반환 (@ResponseBody)** — HTML 페이지를 통째로 주는 것이 아니라, 단순한 문자열 데이터만 본문에 직접 실어 보내는 방식입니다.
