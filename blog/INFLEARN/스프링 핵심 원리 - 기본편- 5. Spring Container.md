# [스프링 핵심 원리 - 기본편] 5. Spring Container

## 원문

https://ch010104.tistory.com/223

## 핵심 요약

- **1. 스프링 컨테이너 생성** — ApplicationContext를 스프링 컨테이너라고 하며, 이는 인터페이스임.
- **2. 스프링 빈 등록** — 스프링 컨테이너는 파라미터로 넘어온 구성 정보(AppConfig.class)를 확인하여 객체를 생성하고 빈 저장소에 등록
- **3. 스프링 빈 의존관계 설정 (준비 및 완료)** — 빈 생성 단계가 끝나면, 스프링 컨테이너는 설정 정보를 참고하여 의존관계 주입(DI)을 수행.
- **4. 컨테이너의 모든 빈 조회** — getBeanDefinitionNames() : 등록된 Bean의 이름을 가져옴
