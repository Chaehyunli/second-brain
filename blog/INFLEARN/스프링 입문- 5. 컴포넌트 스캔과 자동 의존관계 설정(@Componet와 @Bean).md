# [스프링 입문] 5. 컴포넌트 스캔과 자동 의존관계 설정(@Componet와 @Bean)

## 원문

https://ch010104.tistory.com/208

## 핵심 요약

- **1. 컴포넌트 스캔과 자동 의존관계 설정** — 스프링이 애플리케이션 실행 시 @Component와 관련된 어노테이션을 찾아 자동으로 빈(Bean)을 생성하고 연결하는 방식입니다.
- **핵심 어노테이션** — @Component: 스프링 빈으로 자동 등록됩니다.
- **2. 자바 코드로 직접 스프링 빈 등록하기** — 향후 구현 클래스를 변경해야 할 상황(예: 메모리 리포지토리를 실제 DB 리포지토리로 교체)이 있다면, 컴포넌트 스캔 대신 설정 파일을 통해 수동으로 등록하는 것이 유리합니다.
- **3. 핵심 참고 사항 및 주의점** — 싱글톤 (Singleton): 스프링은 빈을 등록할 때 기본적으로 유일하게 하나만 등록해서 공유합니다.
