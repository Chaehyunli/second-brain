# [스프링 MVC 1편 - 백엔드 웹 개발 핵심 기술] 2. HTML, HTTP API, CSR, SSR

## 원문

https://ch010104.tistory.com/253

## 핵심 요약

- **🌐 웹 개발 핵심 개념 정리: HTML, HTTP API, CSR, SSR** — 웹 개발에서 리소스를 전달하고 화면을 그리는 방식은 크게 4가지 관점에서 이해할 수 있습니다.
- **📁 정적 리소스 (Static Resources)** — 특징: 서버에 미리 저장된 파일을 그대로 전달합니다.
- **📄 HTML 페이지 (Dynamic HTML)** — 특징: 사용자의 요청에 따라 서버에서 HTML을 동적으로 생성하여 전달합니다.
- **2. HTTP API** — 데이터 중심의 통신 방식으로, 화면(UI)이 아닌 데이터 자체를 주고받는 것이 목적입니다.
