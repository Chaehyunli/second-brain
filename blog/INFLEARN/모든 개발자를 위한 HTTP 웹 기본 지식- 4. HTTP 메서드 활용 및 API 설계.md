# [모든 개발자를 위한 HTTP 웹 기본 지식] 4. HTTP 메서드 활용 및 API 설계

## 원문

https://ch010104.tistory.com/244

## 핵심 요약

- **1. 클라이언트에서 서버로 데이터 전송 방식** — 데이터를 전달하는 방식은 크게 두 가지 경로를 이용합니다.
- **데이터 전송의 4가지 상황** — 정적 데이터 조회: 이미지, 정적 텍스트 문서 조회 (쿼리 파라미터 미사용, 경로만으로 조회).
- **2. HTML Form을 통한 데이터 전송** — HTML Form 태그는 기본적으로 GET과 POST만 지원한다는 제약이 있습니다.
- **3. HTTP API 데이터 전송** — 현대적인 웹 개발에서 가장 많이 사용되는 방식입니다.
