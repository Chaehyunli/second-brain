# [스프링 MVC 2편 - 백엔드 웹 개발 핵심 기술] 11. 파일 업로드

## 원문

https://ch010104.tistory.com/293

## 핵심 요약

- **1. 파일 업로드 소개** — 일반적으로 사용하는 HTML Form을 통한 파일 업로드를 이해하려면 먼저 폼을 전송하는 두 가지 방식(application/x-www-form-urlencoded, multipart/form-data)의 차이를 명확히 이해해야 합니다.
- **1) application/x-www-form-urlencoded 방식** — HTML Form 데이터를 서버로 전송하는 가장 기본적인 방법입니다.
- **2) multipart/form-data 방식** — 문자와 바이너리 데이터를 동시에 한 번에 전송할 수 있도록 고안된 방식입니다.
- **웹 브라우저가 생성한 요청 HTTP 메시지 예시** — 헤더의 Content-Type에 boundary(경계 구분선) 키가 자동 생성됩니다.
