## 핵심 요약

- **📌1. 인터페이스 기본 사용법** — Person 인터페이스는 name, age 프로퍼티를 갖는 객체의 구조를 정의
- **2. 메서드 정의 방식** — 호출 시그니처 방식은 오버로딩이 가능하지만, 함수 타입 표현식은 불가능
- **3. 메서드 오버로딩 (Method Overloading)** — 동일한 함수 이름에 대해 다양한 파라미터 형태를 정의할 수 있음!
- **⚠ 5. 인터페이스의 한계점** — 인터페이스는 Union, Intersection 타입을 직접 표현할 수 없음.
