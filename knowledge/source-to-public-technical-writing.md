# 기준본에서 공개 기술 글로 전개하는 방법

## 핵심
학습 기준본과 공개 기술 글은 같은 문서를 복제하는 관계가 아니라, 원문 근거와 독자용 설명을 분리하는 관계다. 기준본은 원문의 개념·코드·실습 맥락을 보존하고, 공개 글은 이해하기 위한 흐름과 핵심을 재구성한다.

## 적용 기준
- 공개 글은 원문 URL과 파생 관계를 잃지 않는다.
- 원본 코드·로그·측정 조건처럼 근거가 되는 세부사항은 기준본에서 보존하고, 공개 글에서 단순화할 경우 원래 의미를 바꾸지 않는다.
- 제목 변경이나 파일명 변경은 URL·원본 ID를 기준으로 추적한다.

## 주의점 또는 한계
기준본이 존재한다고 해서 공개 글의 모든 해석이 기준본의 직접 인용이라는 뜻은 아니다. 공개 글에 새 판단이나 외부 자료가 들어가면 별도 출처·확인일이 필요하다.
