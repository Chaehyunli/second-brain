# 기준본에서 공개 기술 글로 전개하는 방법

## 목적과 독자
학습 기준본은 원문의 개념·코드·실습 맥락을 보존하고, 공개 글은 독자가 이해할 흐름으로 재구성한다. 둘은 같은 문서를 복제하는 관계가 아니다.

## 기준본과 공개 글의 역할 분리
SKALA Vue Day4는 UI 라이브러리 설치·전역 등록의 학습 맥락을, Tistory 글은 같은 주제를 공개 설명으로 전개한 기록이다.

## 파생 관계와 추적 정보
원문 URL·Notion ID 같은 안정 식별자로 파생 관계를 추적한다. 제목이나 파일명이 바뀌어도 출처 경로와 확인일을 잃지 않는다.

## 보존·재구성의 경계
코드, 로그, 측정 조건처럼 사실을 지지하는 세부사항은 기준본에서 보존한다. 공개 글에서 단순화해도 의미를 바꾸지 않으며 새 해석·외부 자료에는 별도 출처를 붙인다.

## 연결된 지식과 발행 전 점검
[[knowledge/vue-application-composition]]은 Day2–Day4 기준본을 가로질러 만든 재사용 가능한 개념 지도다. 공개 전에는 파생 관계, 원문 링크, 새 주장 출처, 독자용 설명이 서로 맞는지 확인한다.
